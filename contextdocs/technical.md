## Technical Architecture (Socio-Technical Operating System)

### 1. SYSTEM DEFINITION

Konma Xperience is a **bounded socio-technical operating node (STI)** that integrates:

- physical infrastructure (villa)
- human roles (team)
- operational workflows (food + service)
- digital system (dashboard + automation)
- governance (decision + validation rules)

### Core System Equation

```
Konma Xperience = Physical Space + Human Roles + Execution Engine + Data + Governance
```

### LAYER 6 — EXECUTION ENGINE

### Task System

Each task contains:

- owner
- role
- mission + quest mapping
- status
- priority
- XP
- readiness contribution
- dependency
- evidence

### Task Types

- CORE → mission-aligned
- ADHOC → admin-injected
- IMPROVEMENT → optimization

### Execution Rules

- CORE tasks drive mission
- ADHOC tasks handle real-world variability
- IMPROVEMENT tasks refine system

### LAYER 7 — VALIDATION ENGINE

### Validation Logic

```
IF task.status == DONE
AND evidence exists
AND evidence approved
→ task.valid = TRUE
```

### Approval Gates

| Domain | Required Approval |
| --- | --- |
| Food | Sadhana + Anchitha |
| Pricing | Hasmitha + Anchitha |
| Procurement | Surya + Sadhana |
| Experience | Anchitha + Advi |
| Tech | Vinit + Founder |
| Hiring | Sathya + Founder |

The system is successful if:

- all work flows through the system
- no task exists without ownership
- no completion exists without evidence

- readiness reflects reality
