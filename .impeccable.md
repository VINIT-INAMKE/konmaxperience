## Design Context

### Users
**Internal (Ops)**: Team members across roles (Frontend Lead, Backend Lead, BI, Procurement, Talent, Tech, Design/Outreach, Founder/Admin) coordinating daily operations of a 4000 sq ft villa ecosystem. They manage missions, quests, tasks, approvals, KPIs, and governance. They need a command center that feels both powerful and motivating — like a game they're winning.

**Public (Customers)**: Guests and visitors browsing menus, booking events, and leaving feedback. They need a clean, inviting, hospitality-grade experience that feels effortless and trustworthy.

### Brand Personality
**Bold, Playful, Ambitious.** Konma Xperience is a food-first socio-technical OS that gamifies real work. The interface should feel like a premium tool built by people who care deeply about craft — not a generic dashboard. It has the precision of Linear but the soul of a creative studio.

**Emotional targets (ops)**: Confidence & clarity ("I know exactly what to do"), energy & motivation ("I'm leveling up"), calm & control ("nothing is missed"), pride & ownership ("my work matters").

**Emotional targets (public)**: Warmth, trust, delight — a seamless hospitality experience.

### Aesthetic Direction
- **Visual tone**: Sharp, clean, confident. Dark mode by default for ops (command center energy). Light mode for public (warm, approachable).
- **References**: Linear and Notion for their speed, clarity, and professional polish. Beyond that, building something unique — a gamified ops tool with hospitality warmth.
- **Anti-references**: Generic admin templates. Cluttered dashboards. Dull enterprise software. Overly playful designs that sacrifice clarity. AI-generated slop.
- **Theme**: OKLCH neutral palette (black/white/gray) with purposeful accent colors — amber for approvals/warnings, blue for decisions/info, purple for charts/data, red for destructive actions, golden amber for ratings. MagicCard purple-to-pink gradients for featured content.

### Design Principles

1. **Clarity over decoration** — Every element earns its space. Information hierarchy is king. If something doesn't help the user act or understand, remove it.

2. **Momentum through gamification** — XP, levels, quests, and celebrations aren't gimmicks — they're core to the experience. Progress should feel tangible and rewarding. Use motion (BlurFade, confetti, level-up glows) to reinforce achievement.

3. **Professional warmth** — Sharp enough for a power user, warm enough for a hospitality brand. Avoid cold clinical aesthetics. The dark theme should feel premium, not intimidating.

4. **Consistency is trust** — Use the design system (shadcn/ui base-nova, OKLCH tokens, Plus Jakarta Sans, established spacing). Deviations erode trust. Every component should feel like it belongs to the same family.

5. **Motion with purpose** — Animations serve UX, not ego. Staggered reveals orient users. Hover effects confirm interactivity. Celebrations mark real accomplishment. Never animate just because you can.

### Technical Foundation
- **Framework**: Next.js 16 + TypeScript
- **Styling**: Tailwind CSS v4 + OKLCH color tokens
- **Components**: shadcn/ui (base-nova style) + Magic UI + Spectrum UI
- **Motion**: Framer Motion (BlurFade, MagicCard hover, staggered reveals)
- **Icons**: Lucide React
- **Charts**: Recharts with purple gradient palette
- **Fonts**: Plus Jakarta Sans (primary — geometric, friendly, bold), Geist Mono (code/data)
- **Radius**: 10px base with calculated variants (6px-26px scale)
- **Accessibility**: Best effort — focus states, labels, keyboard nav, semantic HTML. No strict WCAG compliance target.
