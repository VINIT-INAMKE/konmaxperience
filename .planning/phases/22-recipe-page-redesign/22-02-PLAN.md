**4. Create `frontend/components/ops/operations/recipes/RecipeBuilderPage.tsx`:**

This is the main builder component. It manages all recipe state and renders the two-column layout (per D-01 and UI spec).

Props:
```typescript
interface RecipeBuilderPageProps {
  recipeId?: string;
}
```

State management:
- `name` (string), `description` (string), `prepSteps` (string), `cookingMethod` (string)
- `yieldQty` (string), `yieldUnit` (string), `portionSize` (string), `shelfLifeHours` (string)
- `brandId` (string | null), `zoneId` (string | null), `imageUrl` (string)
- `status` (RecipeStatus), defaulting to `'draft'`
- `bomLines` (BomLineState[])
- `isDirty` (boolean) — set to true on any field change
- `isSaving` (boolean)

Data fetching:
- `useQuery(['recipe', recipeId], ...)` — fetch recipe if recipeId provided. On success, populate all state fields from the response, including mapping `RecipeLines` to `BomLineState[]` (setting `item_name` from the ingredient/source_recipe name, `quantity` as string).
- `useQuery(['brands'], () => apiClient.get<Brand[]>('/brands'))` — for metadata grid
- `useQuery(['zones'], () => apiClient.get<Zone[]>('/zones'))` — for metadata grid

Save mutation:
- `useMutation` that calls `apiClient.patch('/recipes/' + recipeId, payload)` for existing recipes or `apiClient.post('/recipes', payload)` for new recipes
- Payload maps state back to DTO format: `{ name, description, prep_steps: prepSteps, cooking_method: cookingMethod, yield_qty: parseFloat(yieldQty), yield_unit: yieldUnit, portion_size: portionSize, shelf_life_hours: shelfLifeHours ? parseInt(shelfLifeHours) : undefined, brand_id: brandId || undefined, zone_id: zoneId || undefined, image_url: imageUrl || undefined, bom_lines: bomLines.filter(l => l.item_id).map(l => ({ input_type: l.input_type, item_id: l.item_id, quantity: parseFloat(l.quantity), unit: l.unit, prep_notes: l.prep_notes || undefined })) }`
- On success: `setIsDirty(false)`, `toast.success('Recipe saved.')`, invalidate query cache, if new recipe navigate to `/operations/recipes/${response.id}`

`beforeunload` hook (reuse GuideEditorClient.tsx pattern):
