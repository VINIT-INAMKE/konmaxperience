Expand `backend/src/chat/chat.service.ts` from the Plan 01 stub into a full service. Inject PrismaService and PusherService via constructor. Implement these methods:

**1. `createConversation(dto: CreateConversationDto, userId: string)`:**
- For `type: 'direct'`: Check if a direct conversation already exists between userId and dto.participant_ids[0] by querying ConversationParticipant. The query: find conversations where type='direct' AND both user IDs appear as participants. Use a raw-ish approach: find all conversation_ids where user_id = userId, then check if any of those also has the target user and type='direct'. If found, return the existing conversation (per D-10 duplicate prevention). If not found, create a new Conversation with type='direct', name=null, created_by=userId. Create two ConversationParticipant rows (userId and the target user).
- For `type: 'group'`: Validate dto.name is provided (throw BadRequestException if not). Create Conversation with type='group', name=dto.name, created_by=userId. Create ConversationParticipant rows for all dto.participant_ids PLUS the creator (userId). Per D-11, only FOUNDER_ADMIN can create groups — but enforcement is in the controller, not the service.
- Return the created/found conversation with participants included (include: { participants: { include: { user: { select: { id, name, email } } } } }).

**2. `getConversations(userId: string)`:**
- Find all conversations where the user is a participant. Query: `prisma.conversation.findMany({ where: { participants: { some: { user_id: userId } } }, include: { participants: { include: { user: { select: { id: true, name: true } } } }, messages: { take: 1, orderBy: { created_at: 'desc' }, include: { sender: { select: { id: true, name: true } } } } }, orderBy: { updated_at: 'desc' } })`.
- Return the array.

**3. `getAllConversations()` (admin only):**
- Same as getConversations but no user filter: `prisma.conversation.findMany({ include: { participants: { include: { user: { select: { id: true, name: true } } } }, messages: { take: 1, orderBy: { created_at: 'desc' }, include: { sender: { select: { id: true, name: true } } } } }, orderBy: { updated_at: 'desc' } })`.

**4. `getMessages(conversationId: string, cursor?: string, take: number = 30)`:**
- Cursor-based pagination: `prisma.message.findMany({ where: { conversation_id: conversationId }, ...(cursor ? { cursor: { id: cursor }, skip: 1 } : {}), take, orderBy: { created_at: 'desc' }, include: { sender: { select: { id: true, name: true } } } })`.
- Reverse the result array so messages are in chronological order (oldest first) for the frontend.
- Return `{ messages: reversed, nextCursor: hasMore ? lastItem.id : null }` where hasMore = result.length === take.

**5. `createMessage(conversationId: string, dto: CreateMessageDto, senderId: string)`:**
- Create the message: `prisma.message.create({ data: { conversation_id: conversationId, sender_id: senderId, content: dto.content || null, attachment_key: dto.attachment_key || null, attachment_url: dto.attachment_url || null, attachment_name: dto.attachment_name || null, attachment_type: dto.attachment_type || null }, include: { sender: { select: { id: true, name: true } } } })`.
- After DB write, update conversation.updated_at: `prisma.conversation.update({ where: { id: conversationId }, data: { updated_at: new Date() } })`.
- After DB write, trigger Pusher event (per D-09, D-21): `this.pusherService.trigger('private-chat-' + conversationId, ChatEvent.NEW_MESSAGE, { id: message.id, sender_id: message.sender_id, sender_name: message.sender.name, content: message.content, attachment_url: message.attachment_url, attachment_type: message.attachment_type, attachment_name: message.attachment_name, created_at: message.created_at.toISOString() })`.
- Return the created message.

**6. `markRead(conversationId: string, userId: string)`:**
- Update: `prisma.conversationParticipant.updateMany({ where: { conversation_id: conversationId, user_id: userId }, data: { last_read_at: new Date() } })`.
- Trigger Pusher: `this.pusherService.trigger('private-chat-' + conversationId, ChatEvent.MESSAGE_READ, { userId, readAt: new Date().toISOString() })`.

**7. `getConversation(conversationId: string)`:**
- Single conversation with participants: `prisma.conversation.findUnique({ where: { id: conversationId }, include: { participants: { include: { user: { select: { id: true, name: true } } } } } })`.
- Throw NotFoundException if null.

**8. `addMembers(conversationId: string, userIds: string[])`:**
- Per D-12. For each userId not already a participant, create a ConversationParticipant. Use createMany with skipDuplicates.

**9. `removeMembers(conversationId: string, userIds: string[])`:**
- Per D-12. Delete ConversationParticipant rows: `prisma.conversationParticipant.deleteMany({ where: { conversation_id: conversationId, user_id: { in: userIds } } })`.

The `checkParticipantAccess` method from Plan 01 remains unchanged.

IMPORTANT anti-patterns from research:
- Trigger Pusher AFTER database write, never before (data consistency).
- Do NOT instantiate Pusher inside methods — use the injected PusherService singleton.

**1. Expand `backend/src/chat/chat.controller.ts`:**

Keep the existing `@Post('auth')` endpoint from Plan 01. Add these new endpoints to the same controller (route prefix `'chat'`):

```
POST   /chat/conversations          — Create conversation (direct or group)
GET    /chat/conversations           — Get user's conversations
GET    /chat/conversations/:id       — Get single conversation with participants
GET    /chat/conversations/:id/messages  — Get messages (cursor pagination)
POST   /chat/conversations/:id/messages  — Send message
PATCH  /chat/conversations/:id/read      — Mark conversation as read
PATCH  /chat/conversations/:id/members   — Add members to group (admin only)
DELETE /chat/conversations/:id/members   — Remove members from group (admin only)
GET    /chat/admin/conversations         — All conversations (admin only)
GET    /chat/admin/conversations/:id/messages — Any conversation's messages (admin only)
```

Implementation for each:

**POST /chat/conversations:**
- `@Post('conversations')` — Takes CreateConversationDto. Extract userId from req.user.id.
- For group type (dto.type === 'group'): check `req.user.roleCode === RoleCode.FOUNDER_ADMIN`, throw ForbiddenException if not. Per D-11.
- Call `chatService.createConversation(dto, userId)`.

**GET /chat/conversations:**
- `@Get('conversations')` — Extract userId from req.user.id.
- Call `chatService.getConversations(userId)`.

**GET /chat/conversations/:id:**
- `@Get('conversations/:id')` — Takes id from @Param.
- Verify access: either user is participant OR user is admin/tech (same pattern as auth endpoint).
- Call `chatService.getConversation(id)`.

**GET /chat/conversations/:id/messages:**
- `@Get('conversations/:id/messages')` — Takes id from @Param, optional `cursor` and `take` from @Query.
- Verify access (participant or admin/tech).
- Call `chatService.getMessages(id, cursor, take ? parseInt(take) : 30)`.

**POST /chat/conversations/:id/messages:**
- `@Post('conversations/:id/messages')` — Takes CreateMessageDto. Verify participant access (NOT admin bypass — per D-18 admin cannot send). Throw ForbiddenException if not participant.
- Validate that at least content or attachment_url is provided (throw BadRequestException if both null/empty).
- Call `chatService.createMessage(id, dto, userId)`.

**PATCH /chat/conversations/:id/read:**
- `@Patch('conversations/:id/read')` — @HttpCode(204). Extract userId.
- Call `chatService.markRead(id, userId)`. Return nothing (204).

**PATCH /chat/conversations/:id/members:**
- `@Patch('conversations/:id/members')` — `@RequiresPermission(Permission.MANAGE_SYSTEM)`.
- Body: `{ user_ids: string[] }`. Call `chatService.addMembers(id, user_ids)`.

**DELETE /chat/conversations/:id/members:**
- `@Delete('conversations/:id/members')` — `@RequiresPermission(Permission.MANAGE_SYSTEM)`.
- Body: `{ user_ids: string[] }`. Call `chatService.removeMembers(id, user_ids)`.

**GET /chat/admin/conversations:**
- `@Get('admin/conversations')` — `@RequiresPermission(Permission.MANAGE_SYSTEM)`.
- Call `chatService.getAllConversations()`.

**GET /chat/admin/conversations/:id/messages:**
- `@Get('admin/conversations/:id/messages')` — `@RequiresPermission(Permission.MANAGE_SYSTEM)`.
- Takes optional `cursor` and `take` from @Query.
- Call `chatService.getMessages(id, cursor, take ? parseInt(take) : 30)`.

For access checks in non-admin endpoints, create a private helper method `ensureAccess(conversationId, user)` that checks participant OR admin role.
