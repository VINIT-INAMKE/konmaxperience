## Spacing Scale

Declared values (multiples of 4 only). Consistent with Phases 15 and 16 — continuity required.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Avatar badge dot position, unread indicator gap, check mark icon gap |
| sm | 8px | Message bubble internal horizontal padding, conversation list item vertical gap, attachment thumbnail gap |
| md | 16px | Conversation list item padding, message thread horizontal padding, compose area vertical padding |
| lg | 24px | Chat page horizontal padding (desktop), header area padding, section dividers |
| xl | 32px | Thread area top/bottom margin for first/last message |
| 2xl | 48px | Major empty state illustration-to-text gap |
| 3xl | 64px | Empty state vertical centering offset |

Exceptions:
- Conversation list panel width: 320px (desktop fixed left panel — layout constraint, not a spacing token)
- Message max bubble width: 72% of the thread panel width (prevents full-width bubbles on wide screens; matches iMessage/WhatsApp convention)
- Compose area min-height: 56px (accounts for Send button + padding at resting state)
- Compose area max-height: 200px (textarea grows to 200px before scrolling)
- Touch targets (mobile send button, attachment button): 44px × 44px — matches mobile accessibility minimum
- Avatar sizes: 32px default (`size-8`), 24px compact in message bubble (`size-6`), 40px in group header (`size-10`)

## Typography

All values consistent with Phases 15 and 16.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body / Message text | 14px | 400 (regular) | 1.5 | Message bubble content, compose textarea, conversation preview snippet |
| Label / UI text | 12px | 400 (regular) | 1.4 | Timestamp, read receipt label, "is typing..." indicator, unread count badge, message metadata |
| Heading (conversation name) | 16px | 600 (semibold) | 1.3 | Active conversation header name, conversation list item name |
| Display (page title) | 20px | 600 (semibold) | 1.2 | "Chat" page heading on empty state, tab label when active |

Final type scale: **12, 14, 16, 20px** — 4 sizes, 2 weights (400, 600).

Note: Message body uses 14px (not 16px as in guide prose) because chat UIs conventionally use tighter type for density. This is intentional and distinct from the guide reading view.

Font: `Plus Jakarta Sans` (`--font-sans`) throughout. No secondary display font.

## Color

All color values reference shadcn CSS custom properties from `frontend/app/globals.css`.

| Role | CSS Token | Approx Value (light) | Usage |
|------|-----------|---------------------|-------|
| Dominant (60%) | `var(--background)` | `oklch(1 0 0)` (#ffffff) | Page background, thread area background, conversation list background |
| Secondary (30%) | `var(--card)` / `var(--muted)` | `oklch(1 0 0)` / `oklch(0.97 0 0)` | Conversation list panel background (`var(--card)`), incoming message bubble background (`var(--muted)`), compose area background (`var(--card)`) |
| Accent (10%) | Brand gradient `#9E7AFF → #FE8BBB` | purple→pink | Reserved: outgoing message bubble background (sender's own messages only); active conversation item `bg-primary` fill |
| Destructive | `var(--destructive)` | `oklch(0.577 0.245 27.325)` | No destructive actions in this phase — token declared for completeness |

Accent reserved for:
1. Outgoing (own) message bubbles — `bg-primary text-primary-foreground` fill (matches existing `NavLink` active pattern using `--primary`)
2. Active conversation item in the list — `bg-primary/10` background tint with `text-primary` name text
3. Unread message count badge — `bg-primary text-primary-foreground rounded-full` small badge

Incoming (other person's) message bubbles: `bg-muted text-foreground` — neutral, not accented.

Policy notice banner: `bg-amber-500/10 border-amber-500/20 text-amber-600` — consistent with draft banners in Phase 16 admin CMS.

Typing indicator text: `text-muted-foreground` (12px italic) — unobtrusive.

Read receipt colors:
- Sent (delivered, unread): `text-muted-foreground/50` double check icon
- Read: `text-primary` (accent blue/primary color) double check icon — WhatsApp convention

Dark mode: all tokens auto-resolve via `.dark` CSS class. No additional overrides needed.

## Layout Contract

### Route Structure

| Route | Page | Layout |
|-------|------|--------|
| `/chat` | Split-panel chat page — conversation list left, active thread right | Ops layout (existing sidebar stays). Chat content replaces the default `p-4 sm:p-6 max-w-[1200px] mx-auto` wrapper — chat must fill the full available height. |

### Layout Override for /chat

The ops layout wraps children in `<div className="p-4 sm:p-6 max-w-[1200px] mx-auto w-full">`. The `/chat` page must break out of this constraint to achieve a full-height split panel. This is handled by setting the page wrapper to `h-full overflow-hidden` with `flex` at the route level, overriding the outer padding via negative margin or by using a page-level full-height container.

Concrete approach: wrap the chat page in `<div className="h-[calc(100vh-0px)] -m-4 sm:-m-6 flex overflow-hidden">` to undo the layout's padding and fill the viewport. The chat page owns its own scroll regions.

### Desktop Layout (lg and above)

```
┌─────────────────────────────────────────────────────┐
│  Ops Sidebar (240px)  │    Chat Page (flex-1)        │
│                       │ ┌──────────┬───────────────┐ │
│                       │ │  Panel   │  Thread Area  │ │
│                       │ │  (320px) │   (flex-1)    │ │
│                       │ │ Conv List│  Msgs + Input │ │
│                       │ └──────────┴───────────────┘ │
└─────────────────────────────────────────────────────┘
```

- Left panel: `w-[320px] shrink-0 border-r flex flex-col bg-card`
- Right thread area: `flex-1 flex flex-col min-w-0 bg-background`
- The two panels together fill the space between ops sidebar and right edge.

### Mobile Layout (below lg)

On mobile, conversation list and thread are shown as separate views:
- Default view: full-width conversation list
- After selecting conversation: conversation list slides/hides, thread takes full width
- Back button in thread header returns to conversation list
- The mobile header in ops layout remains visible above the chat panels

### Left Panel — Conversation List

**Panel header:**
- `flex items-center justify-between px-4 h-14 border-b shrink-0`
- Left: `"Chat"` heading (16px / semibold)
- Right: `New Chat` button — `Plus` icon, `variant="ghost"`, `size-icon` (`size-8`), `aria-label="New conversation"`
- Admin/tech only: `Tabs` component below the header with two tabs: `"My Chats"` and `"All Conversations"` — `tabs-list` spans full width. Non-admin users: no tabs, just the conversation list directly.

**Tab layout (admin/tech only):**
- `<Tabs defaultValue="my-chats">` wrapping both panel content and thread area
- `<TabsList className="w-full rounded-none border-b h-9">` with two `<TabsTrigger className="flex-1 text-[12px]">` items
- Tab labels: `"My Chats"` and `"All Conversations"`

**Conversation list items:**
- `flex items-center gap-3 px-4 py-3 cursor-pointer hover:bg-muted/50 transition-colors rounded-none`
- Active item: `bg-primary/10` background, conversation name in `text-primary font-semibold`
- Layout anatomy (left to right):
  - Avatar (32px) with `AvatarFallback` initials — for group chats, show group icon (`Users` Lucide icon) in muted background
  - Center column (flex-1, min-w-0):
    - Row 1: Conversation name (14px / semibold, `truncate`) + timestamp right-aligned (12px / `text-muted-foreground`)
    - Row 2: Last message preview snippet (12px / `text-muted-foreground`, `truncate`) + unread badge right-aligned
  - Unread badge: `bg-primary text-primary-foreground text-[10px] font-semibold min-w-[18px] h-[18px] rounded-full flex items-center justify-center` — shown only when unread count > 0
- `Separator` between items: none (clean list, item hover background provides visual separation)
- List scrolls inside `<ScrollArea className="flex-1">`

**Section dividers (in "All Conversations" admin view only):**
- "1-1 Chats" and "Group Chats" section headers: `px-4 py-2 text-[11px] font-medium uppercase tracking-wider text-muted-foreground/60` — matches Sidebar section label style

### Right Panel — Message Thread

**Thread header:**
- `flex items-center gap-3 px-4 h-14 border-b shrink-0 bg-card`
- Left (mobile only): Back button — `ChevronLeft` icon, `size-9 rounded-md hover:bg-muted`, `aria-label="Back to conversations"`
- Avatar (32px) + conversation name (16px / semibold) + secondary line with participant names (12px / `text-muted-foreground`, truncated)
- For groups: `Users` icon or group initial avatar + group name + "N members" (12px)
- Right: `MoreVertical` icon button (future-proofed, no menu items in this phase — renders as disabled placeholder or omitted if complexity is a concern; Claude's discretion: omit entirely for phase 21)

**Thread scroll area:**
- `<ScrollArea className="flex-1 px-4">` — vertically scrollable
- Auto-scrolls to bottom on new messages (via `useEffect` + `scrollToBottom` ref)
- `py-4` padding on the scroll content container

**Message bubbles:**

Outgoing (own messages):
```
<div className="flex justify-end mb-2">
  <div className="max-w-[72%] flex flex-col items-end gap-1">
    <div className="bg-primary text-primary-foreground rounded-2xl rounded-br-sm px-3 py-2 text-[14px] leading-[1.5]">
      {message.text}
    </div>
    <div className="flex items-center gap-1 text-[12px] text-muted-foreground">
      <span>{formatTime(message.createdAt)}</span>
      <ReadReceiptIcon readBy={message.readBy} />
    </div>
  </div>
</div>
```

Incoming (other person's messages):
```
<div className="flex justify-start gap-2 mb-2">
  <Avatar size="sm" className="shrink-0 mt-1">
    <AvatarFallback>{initials}</AvatarFallback>
  </Avatar>
  <div className="max-w-[72%] flex flex-col items-start gap-1">
    {/* Show sender name only in group chats */}
    {isGroup && <span className="text-[12px] font-semibold text-muted-foreground px-1">{senderName}</span>}
    <div className="bg-muted text-foreground rounded-2xl rounded-bl-sm px-3 py-2 text-[14px] leading-[1.5]">
      {message.text}
    </div>
    <span className="text-[12px] text-muted-foreground px-1">{formatTime(message.createdAt)}</span>
  </div>
</div>
```

Border radius: `rounded-2xl` (16px) with one corner trimmed toward the avatar:
- Own messages: `rounded-br-sm` (small radius on bottom-right — pointing toward right/bottom)
- Others' messages: `rounded-bl-sm` (small radius on bottom-left — pointing toward left/bottom)

**Date dividers between messages:**
- When message date changes: `<div className="flex items-center gap-3 my-4"><Separator className="flex-1" /><span className="text-[12px] text-muted-foreground shrink-0">{formatDate(date)}</span><Separator className="flex-1" /></div>`

**Image attachments in messages:**
- Inline below text (if text + image) or standalone (image-only message)
- `<img className="max-w-full rounded-xl mt-2 cursor-pointer hover:opacity-90 transition-opacity" style={{ maxWidth: '240px', maxHeight: '240px', objectFit: 'cover' }} />`
- Click to open in `Dialog` lightbox (full-size view with close button)

**File attachments in messages:**
- Non-image files: `<div className="flex items-center gap-2 bg-background/50 rounded-lg px-3 py-2 mt-2 border"><Paperclip className="size-4 shrink-0 text-muted-foreground" /><span className="text-[13px] truncate">{filename}</span><a href={fileUrl} download className="ml-auto"><Download className="size-4 text-muted-foreground hover:text-foreground" /></a></div>`
- Treated as a contained block inside the message bubble area (same max-width constraint)

**Typing indicator:**
- Shown below last message when another user is typing
- `<div className="flex items-center gap-2 px-1 mb-2"><Avatar size="sm"><AvatarFallback>{initial}</AvatarFallback></Avatar><span className="text-[12px] text-muted-foreground italic">{name} is typing...</span></div>`
- Disappears when typing stops (Pusher client event timeout: 3 seconds after last typing event)

**Read receipts (double check marks):**
- Icon: two overlapping `Check` icons (Lucide), 12px, `text-muted-foreground/50` when sent, `text-primary` when all recipients have read
- Positioned below-right of own message bubble timestamp area

**Compose area:**
- `flex items-end gap-2 px-4 py-3 border-t bg-card shrink-0`
- Attachment button: `<button aria-label="Attach file" className="flex items-center justify-center size-11 rounded-md hover:bg-muted transition-colors shrink-0"><Paperclip className="size-5 text-muted-foreground" /></button>`
- Textarea: `<textarea className="flex-1 resize-none bg-transparent text-[14px] leading-[1.5] placeholder:text-muted-foreground outline-none py-2 min-h-[40px] max-h-[200px]" placeholder="Type a message..." rows={1} />` — auto-expands on content (JavaScript-driven height based on `scrollHeight`)
- Send button: `<button aria-label="Send message" disabled={!hasContent} className="flex items-center justify-center size-11 rounded-md bg-primary text-primary-foreground hover:bg-primary/90 transition-colors disabled:opacity-40 disabled:cursor-not-allowed shrink-0"><Send className="size-5" /></button>`
- Send on Enter key (Shift+Enter = newline)

**Policy notice:**
- Shown as a one-time banner at the top of the thread area (above message scroll area) on first load
- `<div className="flex items-center gap-2 px-4 py-2 bg-amber-500/10 border-b border-amber-500/20 text-[12px] text-amber-600 shrink-0"><Info className="size-3 shrink-0" />Conversations may be reviewed by admins for operational purposes.<button onClick={dismiss} className="ml-auto text-amber-600/70 hover:text-amber-600"><X className="size-3" /></button></div>`
- Dismissed per-session (no persistence needed — reappears on page reload, acceptable for an 8-person team)

**Admin "All Conversations" — read-only overlay:**
- When admin is viewing someone else's chat via "All Conversations" tab, compose area is replaced by:
- `<div className="flex items-center justify-center gap-2 px-4 py-3 border-t bg-muted/50 text-[13px] text-muted-foreground"><EyeOff className="size-4" />Read-only — you are viewing this conversation as an admin.</div>`

### New Conversation Flows

**New 1-1 Chat (Dialog — "New Chat" button):**
- `Dialog` (not Sheet — dialog is appropriate for a short user-picker step)
- `DialogTitle`: `"New Chat"` (16px / semibold)
- `DialogDescription`: `"Start a 1-1 conversation with a team member."`
- User picker: `Command` component (Combobox-style) with search input and scrollable user list
  - Each user row: Avatar (24px) + name (14px) + role badge (12px / `variant="secondary"`)
  - Shows all active users except the current user
  - Selecting a user either opens an existing conversation with them or creates a new one
- `DialogFooter`: Cancel button + `"Start Chat"` primary button (disabled until user selected)
- Existing conversation: if a 1-1 conversation already exists with the selected user, navigate to it instead of creating a duplicate.

**New Group Chat (Dialog — admin only, same "New Chat" button with conditional rendering):**
- Same `Dialog` but with additional fields shown only for FOUNDER_ADMIN:
  - `Input` for group name (required, `placeholder="Group name"`)
  - Multi-select user list (checkboxes, `Checkbox` component)
  - Avatar/icon field: optional — shows `Users` Lucide icon by default (no custom upload in this phase; Claude's discretion)
- `DialogTitle`: `"New Group Chat"`
- `DialogDescription`: `"Create a group conversation with selected team members."`
- `DialogFooter`: Cancel + `"Create Group"` primary button (disabled until name filled and ≥2 members selected)

**Group management (admin only — in group thread header area):**
- `MoreVertical` dropdown on group thread header (admin viewing group only):
  - `"Manage Members"` → opens Sheet with member list (add/remove checkboxes)
  - Sheet: `side="right"`, `max-w-[400px]`, title `"Group Members"`, member list with remove buttons (`X` icon, `text-muted-foreground hover:text-destructive`), "Add Members" section with user picker

### Real-time Interactions (Pusher)

| Event | UI Response |
|-------|------------|
| New message arrives in active conversation | Message appended to thread scroll area; scroll to bottom (smooth: `behavior: 'smooth'`); conversation list item preview updates |
| New message arrives in inactive conversation | Unread count badge on conversation list item increments; no notification sound or toast |
| Typing event received | `TypingIndicator` appears below last message; disappears after 3 seconds of no new typing events |
| Read receipt event received | `ReadReceiptIcon` on own messages switches from `text-muted-foreground/50` to `text-primary` |
| User starts typing (own keypress) | Trigger Pusher client event `client-typing` on the conversation's private channel — debounced, fires max once per 2 seconds |

## Component-by-Component Spec

### ConversationList

- `"use client"` component
- Props: `conversations`, `activeId`, `onSelect`, `currentUserId`, `isAdmin`
- Renders: panel header (title + new-chat button), admin tabs (conditional), `<ScrollArea>`, list of `<ConversationItem>`
- On tab switch between "My Chats" and "All Conversations": re-queries from React Query with appropriate filter param
- Handles both 1-1 and group conversations in the same list — groups shown with `Users` icon instead of individual avatar

### MessageThread

- `"use client"` component
- Props: `conversation`, `messages`, `currentUserId`, `isAdmin`, `isReadOnly`
- Sub-areas: `ThreadHeader`, `ScrollArea` (messages), `TypingIndicator` (below message list), `PolicyNotice`, `ComposeArea` (or read-only notice)
- `useEffect` for auto-scroll: `messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' })` triggered on `messages` length change
- Pusher subscription: `useEffect` subscribes to `private-chat-{conversationId}` channel on mount, unsubscribes on unmount

### ComposeArea

- `"use client"` component
- Props: `conversationId`, `onSend`, `disabled`
- Auto-expand textarea: `onInput` sets `element.style.height = 'auto'; element.style.height = element.scrollHeight + 'px'`
- Keyboard: `onKeyDown` — if `Enter` and not `Shift`, `preventDefault()` and call `onSend(value)`
- File input: hidden `<input type="file" accept="image/jpeg,image/png,image/webp,application/pdf,.csv,.xlsx,.xls,.docx,.txt" />` triggered by paperclip button click
- Upload flow: call presign endpoint (`/storage/presign`) → PUT to R2 → resolve public URL → include in message payload

### ReadReceiptIcon

```tsx
// Two overlapping Check icons with conditional color
function ReadReceiptIcon({ readBy, totalRecipients }: { readBy: string[]; totalRecipients: number }) {
  const allRead = readBy.length >= totalRecipients;
  const color = allRead ? 'text-primary' : 'text-muted-foreground/50';
  return (
    <div className={`flex -space-x-1 ${color}`}>
      <Check className="size-3" />
      <Check className="size-3" />
    </div>
  );
}
```
