Per UI-SPEC Section 5 — vertical timeline with 4 checkpoints:

Props: `channel: 'takeaway' | 'delivery'`, `status: string`, `deliveryStatus: string | null`, `timestamps: Record<string, string>`

Build steps array based on channel (per D-12 mapping):
- **Takeaway:** Order Placed, Preparing your order, Ready for Pickup, Picked Up
- **Delivery:** Order Placed, Preparing your order, Out for Delivery, Delivered

Status mapping logic:
- `placed` -> step 1 active
- `preparing` -> step 1 completed, step 2 active
- `ready` (takeaway) -> steps 1-2 completed, step 3 active
- `dispatched` + delivery_status `picked_up` or `in_transit` (delivery) -> steps 1-2 completed, step 3 active
- `served` (takeaway) -> all completed
- delivery_status `delivered` -> all completed

Each checkpoint row per UI-SPEC:

```typescript
const channelRef = useCustomerPusherChannel(
  customer?.id ? `private-customer-${customer.id}` : null
);

useEffect(() => {
  const channel = channelRef.current;
  if (!channel) return;

  const handleStatusChange = (data: { orderId: string; status: string; updatedAt: string }) => {
    if (data.orderId === orderId) {
      setOrder(prev => prev ? { ...prev, status: data.status } : prev);
      setTimestamps(prev => ({ ...prev, [data.status]: data.updatedAt }));
    }
  };

  const handleDeliveryUpdate = (data: { orderId: string; deliveryStatus: string; updatedAt: string }) => {
    if (data.orderId === orderId) {
      setOrder(prev => prev ? { ...prev, delivery_status: data.deliveryStatus } : prev);
      setTimestamps(prev => ({ ...prev, [data.deliveryStatus]: data.updatedAt }));
    }
  };

  channel.bind('order.status-changed', handleStatusChange);
  channel.bind('delivery.updated', handleDeliveryUpdate);

  return () => {
    channel.unbind('order.status-changed', handleStatusChange);
    channel.unbind('delivery.updated', handleDeliveryUpdate);
  };
}, [channelRef.current, orderId]);
```
