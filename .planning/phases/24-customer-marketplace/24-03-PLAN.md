Use `persist` middleware with `name: 'cart-storage'` and `partialize` to persist only `items`, `channel`, `deliveryAddressId`.

- `addItem`: if item exists increment qty, else add with qty 1
- `removeItem`: filter out by menuItemId
- `updateQuantity`: if qty <= 0 remove, else update
- `replaceCart`: wholesale replace (for Redis sync result)
- `getTotalItems`: sum of all quantities
- `getSubtotal`: sum of unitPrice * quantity

**4. useCart hook** (`frontend/hooks/use-cart.ts`):

Wraps `useCartStore` with API sync functionality:

```typescript
export function useCart() {
  const store = useCartStore();
  const { customer } = useCustomerAuth();

  // Sync local cart to Redis on login
  const syncToServer = useCallback(async () => {
    if (!customer?.id) return;
    const { items, channel, deliveryAddressId } = useCartStore.getState();
    if (items.length === 0) return;
    try {
      const result = await apiClient.post<CartData>('/customer/cart/sync', {
        items, channel, deliveryAddressId,
      });
      // Replace local cart with server merge result
      useCartStore.getState().replaceCart(result.items, result.channel, result.deliveryAddressId);
    } catch { /* silent fail — local cart is still usable */ }
  }, [customer?.id]);

  // Checkout — calls POST /customer/orders
  const checkout = useCallback(async () => {
    const response = await apiClient.post<{ razorpay_order_id: string }>('/customer/orders');
    return response;
  }, []);

  // Confirm — calls POST /customer/orders/confirm
  const confirmOrder = useCallback(async (payload: {
    razorpay_order_id: string;
    razorpay_payment_id: string;
    razorpay_signature: string;
  }) => {
    const result = await apiClient.post<CustomerOrder>('/customer/orders/confirm', payload);
    useCartStore.getState().clearCart();
    return result;
  }, []);

  return {
    ...store,
    syncToServer,
    checkout,
    confirmOrder,
    isLoggedIn: !!customer,
  };
}
```

**5. Wire cart sync on OTP login** (per D-02 — cart sync to Redis on OTP verify):

Modify `frontend/hooks/use-customer-auth.ts` to call `syncToServer()` after successful OTP verification. The `verifyOtp` function in this hook is the single entry point for customer login — this is where the sync must happen.

Approach: After the existing `verifyOtp` logic successfully sets the customer state (i.e., OTP verified, JWT cookie set, profile fetched), call the cart sync. Since `useCart` would create a circular dependency if imported directly into `use-customer-auth`, use the Zustand store directly:

```typescript
// At top of use-customer-auth.ts, add imports:
import { useCartStore } from '@/lib/stores/cart-store';
import { apiClient } from '@/lib/api-client';

// Inside verifyOtp success handler, AFTER profile is set and customer state is confirmed:
// Sync local cart to Redis (fire-and-forget, per D-02)
const { items, channel, deliveryAddressId } = useCartStore.getState();
if (items.length > 0) {
  apiClient.post('/customer/cart/sync', { items, channel, deliveryAddressId })
    .then((result: any) => {
      if (result?.items) {
        useCartStore.getState().replaceCart(result.items, result.channel, result.deliveryAddressId);
      }
    })
    .catch(() => { /* silent fail — local cart still usable */ });
}
```

IMPORTANT: This must be fire-and-forget (not awaited) so it does not block the OTP verify response. The local cart remains usable regardless of sync outcome.
