Form fields per UI-SPEC:

- To User: Select component. Label "Delegate To". Options: all users EXCEPT selected from_user. Required. Disabled until from_user is selected.
- Start Date: `<input type="date">` styled with Input component classes. Label "Start". Required.
- End Date: `<input type="date">` styled with Input component classes. Label "End". Required. Must be >= start_date.

Inline validation on end_date: if end_date < start_date, show `<p className="text-sm text-destructive">End date must be after start date.</p>` below the end date field. Link via `aria-describedby`.

Submit: ShimmerButton "Create Delegation". Disabled while submitting or if validation fails.

On submit:
```typescript
await apiClient.post('/delegations', {
  from_user_id: fromUserId,
  to_user_id: toUserId,
  start_date: startDate,   // ISO date string from input
  end_date: endDate,
});
const fromName = users?.find(u => u.id === fromUserId)?.name || 'user';
const toName = users?.find(u => u.id === toUserId)?.name || 'user';
toast.success(`Delegation created. ${toName} can approve on behalf of ${fromName} until ${endDate}.`);
onCreated();
onOpenChange(false);
```

On error: `toast.error('Failed to create delegation. Check the dates and try again.')`.

Dismiss: ghost Button "Discard Delegation".
