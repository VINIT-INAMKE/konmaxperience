**3. DecisionCard.tsx:**
'use client' component. Props: `{ decision: Decision; isExpanded: boolean; onToggle: () => void; isNew?: boolean }`.
Uses MagicCard with `gradientColor="#1a1a2e"`. Wrap in ShineBorder when `isNew` is true (3s timer, then set isNew false).

Layout per UI-SPEC:
- Row 1: title (16px semibold) + Lock icon (14px muted, from lucide `Lock`) if status==='approved' + DecisionTypeBadge + DecisionStatusBadge — all flex items-center gap-2 flex-wrap
- Row 2: context preview truncated to 2 lines (14px muted, `line-clamp-2`)
- Row 3: flex items-center gap-2 — linked mission/task as Badge variant="outline" with `ExternalLink` icon if present, proposer avatar (AvatarFallback 20px initials + name 14px), relative timestamp pushed right with `ml-auto`

On card hover: InteractiveHoverButton "View Detail" at bottom-right corner.

`aria-label="Decision: {title}, status: {status}, type: {type}"` on outer MagicCard div.

Lock icon gets `aria-label="Locked decision"`.

**4. DecisionDetail.tsx:**
'use client' component. Props: `{ decision: Decision; onStatusChange: () => void }`.
Wrap content in BlurFade. Rendered inside a Card with `p-6`.

Sections per UI-SPEC:
- "Context" section: `<p className="text-[14px] font-semibold uppercase tracking-wider text-muted-foreground">Context</p>` then full context text (16px regular, 1.5 line-height)
- "Links" section: only rendered if linked_mission_id or linked_task_id. Show linked mission/task names as Badge pills with ExternalLink icon.
- "History" section: Minimal — show "Status changed to {status}" + timestamp. Only the current status (no history API in Phase 5, per simplified scope).
- Admin actions (visible when `user?.roleCode === RoleCode.FOUNDER_ADMIN`):
  - If status==='proposed': Button "Approve Decision" (primary) — calls `apiClient.patch('/decisions/{id}', { status: 'approved' })`, toast "Decision approved and locked." + Button "Reject Decision" (outline, `border-destructive`) — calls patch with status 'rejected', toast "Decision rejected."
  - If status==='approved': Button "Reopen Decision" (destructive variant) — opens Dialog with title "Reopen this decision?", body "Approved decisions are locked for governance integrity. Reopening sets status back to Proposed.", confirm "Reopen Decision" (destructive), cancel "Keep Locked" (ghost). On confirm: patch with status 'proposed', toast "Decision reopened."

After any status change: call `onStatusChange()` and invalidate `queryClient.invalidateQueries({ queryKey: ['decisions'] })`.

**5. DecisionList.tsx:**
'use client' component. Props: `{ decisions: Decision[]; isLoading: boolean; isError: boolean; newDecisionId: string | null }`.
Manages which card is expanded via `expandedId` state. Only one expanded at a time.

Loading state: 3 skeleton cards `h-[100px] bg-muted/50 animate-pulse rounded-lg`.
Error state: AlertCircle icon + "Couldn't load decisions. Refresh the page or try again."
Empty state per UI-SPEC: ClipboardList icon (48px muted), "No decisions yet" (20px semibold), "Log the first decision to start building your governance trail." (14px muted), ShimmerButton "Log Decision" if user has permission.

Populated state: BlurFade wrapping AnimatedList with `delay={50}`. Each item is DecisionCard with `isExpanded={expandedId === decision.id}` and `onToggle={() => setExpandedId(prev => prev === decision.id ? null : decision.id)}`.
When a card is expanded, render DecisionDetail below it (outside the card, inside the list flow).

`isNew` prop on DecisionCard: set to `decision.id === newDecisionId` for ShineBorder glow.

**6. DecisionForm.tsx:**
'use client' component. Props: `{ open: boolean; onOpenChange: (open: boolean) => void; onCreated: (id: string) => void }`.
Uses Sheet (side="right", className="w-[480px]").

Form fields per UI-SPEC:
- Title: Input, `placeholder="e.g. Switched to presigned URL pattern for evidence storage"`, required

- Context: Textarea, `placeholder="What was decided, why, and by whom?"`, required, min-height 80px
- Linked Mission (optional): Select/Input searching existing missions via `apiClient.get<{id,title}[]>('/missions')`. Optional field.

Submit: ShimmerButton "Log Decision" with `shimmerColor="#4ade80"`. Disabled while submitting (Loader2 + "Saving...").

On submit: POST `/decisions` with `{ title, decision_type, context, linked_mission_id, linked_task_id }`. On success: close sheet, call `onCreated(response.id)`, toast "Decision logged." On error: toast "Failed to log decision. Check your inputs and try again."

Dismiss button: ghost Button "Discard Decision".
