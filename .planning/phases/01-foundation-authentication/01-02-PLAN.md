8. Create `apps/api/src/auth/auth.service.ts`:
   - Inject PrismaService, JwtService, ConfigService
   - **validateUser(email, password):** find user by email (include role), compare password with bcrypt, return user or null. Reject inactive users.
   - **login(user):** Create JwtPayload with userId and roleCode. Sign access token (15m expiry). Sign refresh token (7d expiry). Hash refresh token with SHA-256 (crypto.createHash('sha256').update(refreshToken).digest('hex')). Store hash in RefreshToken table with expires_at. Return { accessToken, refreshToken, user profile }.
   - **refreshToken(refreshTokenValue):** Hash the incoming token. Find matching non-revoked RefreshToken where expires_at > now. If not found, throw UnauthorizedException. Load user. Sign new access token. Return { accessToken }.
   - **logout(refreshTokenHash):** Set revoked_at = now() on the matching RefreshToken row.
   - **logoutAll(userId):** Set revoked_at = now() on ALL RefreshToken rows for that user.
   - **forgotPassword(email):** Find user by email. Generate 32-byte random token (crypto.randomBytes(32).toString('hex')). Hash with SHA-256 and store in PasswordResetToken table with expires_at = now + 15 minutes. Call EmailService.sendPasswordReset(user.email, token, user.name). Return void (always return success to prevent email enumeration -- log if user not found but don't error).
   - **resetPassword(token, newPassword):** Hash incoming token. Find PasswordResetToken where token_hash matches AND expires_at > now AND used_at IS NULL. If not found, throw BadRequestException("Invalid or expired reset link"). Hash new password with bcrypt (12 rounds). Update user password_hash. Set used_at = now() on the token record. Return void.
   - **setPassword(token, newPassword):** Same as resetPassword but for new user initial setup. Identical logic.
