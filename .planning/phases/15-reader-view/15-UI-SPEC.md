## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact element spacing, nav item internal gaps |
| md | 16px | Card padding, prose paragraph gaps |
| lg | 24px | Section card grid gap, page section padding |
| xl | 32px | Guide index grid row gap, page content vertical rhythm |
| 2xl | 48px | Major section breaks between prose blocks |
| 3xl | 64px | Page-level top padding for reading view |

Exceptions:
- Sidebar overlay width: 280px (matches existing ops Sheet drawer pattern from `(ops)/layout.tsx`)
- Prose max-width: 720px (capped reading line for optimal legibility — exceeds 64px token but is a layout constraint, not a spacing token)
- Touch targets (sidebar hamburger): 36px × 36px (`size-9` in Tailwind) — matches existing mobile header button

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body / Prose | 16px | 400 (regular) | 1.75 | Page content paragraphs, list items |
| Label / UI text | 14px | 400 (regular) | 1.5 | Card metadata (page count, read time), nav labels, breadcrumbs |
| Heading (page title) | 24px | 600 (semibold) | 1.2 | Page `<h1>` in reading view |
| Display (section title) | 20px | 600 (semibold) | 1.2 | Section index card title, section page `<h2>` |

Prose content headings (from Tiptap/rendered HTML):
- h2: 20px / weight 600 / line-height 1.2
- h3: 16px / weight 600 / line-height 1.3
- h4: 14px / weight 600 / line-height 1.4

Font: `Geist Sans` (`--font-sans`) throughout. No secondary display font — single typeface system.

## Color

All color values reference shadcn CSS custom properties as defined in `frontend/app/globals.css`.

| Role | CSS Token | Approx Hex (light) | Usage |
|------|-----------|-------------------|-------|
| Dominant (60%) | `var(--background)` | `#ffffff` | Page background, reading area background |
| Secondary (30%) | `var(--card)` / `var(--muted)` | `#ffffff` / `#f7f7f7` | Section index cards, sidebar overlay, nav item hover |
| Accent (10%) | Brand gradient `#9E7AFF → #FE8BBB` | purple→pink | Reserved for: MagicCard border glow on section index cards only; BorderBeam on hovered section cards; sidebar active section indicator dot |
| Section accent color | Dynamic per-section (stored in DB `accent_color` field) | varies | Section card background tint (10% opacity), section page header bar, sidebar section icon color |
| Destructive | `var(--destructive)` | `oklch(0.577 0.245 27.325)` | No destructive actions in this phase — token declared for completeness |

Accent reserved for:
1. MagicCard gradient border glow on section index cards (hover interaction)
2. BorderBeam animation on hovered section index cards
3. Active page indicator in the guide sidebar overlay
4. Section-specific accent: card background tint at 10% opacity, sidebar section-heading icon

Dark mode: all tokens auto-resolve via `.dark` CSS class as defined in `globals.css`. No separate dark-mode overrides needed in components.

Callout block colors (rendered from Tiptap content):
- Tip: `var(--success)` background at 10% opacity, success-colored left border (4px)
- Warning: `oklch(0.75 0.18 75)` (amber) background at 10% opacity, amber left border (4px)
- Info: `var(--info)` background at 10% opacity, info-colored left border (4px)

## Layout Contract

### Route Structure

| Route | Page | Layout |
|-------|------|--------|
| `/guide` | Section index — role-filtered grid of section cards | Ops layout (existing sidebar stays), full-width content area |
| `/guide/[sectionSlug]` | Section page — list of pages in section | Ops layout + guide sidebar overlay trigger |
| `/guide/[sectionSlug]/[pageSlug]` | Page reading view — rendered prose content | Ops layout + guide sidebar overlay, prose constrained to 720px centered |

### Section Index Page (`/guide`)

- **Grid:** 3 columns on `lg`, 2 columns on `md`, 1 column on `sm`
- **Column gap:** 24px (`gap-6`)
- **Card anatomy:**
  - Section icon (Lucide, 32×32, colored with `accent_color`)
  - Section title (20px / semibold)
  - Section description (14px / regular / `text-muted-foreground`)
  - Page count + estimated read time badge: `"8 pages · ~25 min read"` (12px / `text-muted-foreground`)
  - MagicCard wrapper (gradient border glow on hover)
  - BorderBeam on hover (duration 6s, colors from `BEAM_FROM`/`BEAM_TO` in `brand-colors.ts`)
  - Card background tint: section `accent_color` at 10% opacity on hover
- **Card height:** auto (content-driven, minimum ~120px)
- **Card padding:** 24px (`p-6`)
- **Card border-radius:** `rounded-xl` (`var(--radius-xl)`)

### Guide Sidebar Overlay

- **Trigger:** Hamburger/menu button, fixed position — top-left of reading area, always visible on all breakpoints
- **Container:** shadcn `Sheet` component, `side="left"`, `w-[280px]` — matches existing ops mobile sidebar pattern
- **Animation:** Sheet slide-in from left, 300ms ease-out (shadcn Sheet default)
- **Overlay:** `bg-background/80 backdrop-blur-sm` behind the sheet
- **Content anatomy:**
  - "Guide" header (16px / semibold) with `BookOpen` icon (Lucide)
  - Section list: collapsible per section, default expanded
  - Section entry: section icon (16×16, accent color) + section title (14px / semibold)
  - Page links: 14px / regular, indented 16px from section icon
  - Active page: `bg-primary text-primary-foreground` (matches existing NavLink active state)
  - Inactive page: `text-muted-foreground hover:bg-muted hover:text-foreground`
  - Section collapse toggle: ChevronDown/ChevronRight (Lucide, 14px)

### Page Reading View (`/guide/[sectionSlug]/[pageSlug]`)

- **Prose container:** `max-w-[720px] mx-auto w-full px-6 py-16`
- **Page header block:**
  - Breadcrumb: `{Section Title} / {Page Title}` (12px / `text-muted-foreground`, chevron separator)
  - Page title: 24px / semibold (`h1`)
  - Summary: 16px / regular / `text-muted-foreground` (page `summary` field)
  - Metadata row: estimated read time + last updated date (12px / `text-muted-foreground`)
  - Separator (`<hr>` styled as `border-border`) before prose content
- **Prose content:**
  - Rendered via read-only Tiptap instance (`editable: false`) with `@tiptap/react`, `StarterKit`, `Image` extensions
  - `immediatelyRender: false` to prevent hydration mismatch
  - Prose typography class applied to the editor div: body 16px / line-height 1.75
  - Inline images: `max-w-full` within prose container, `rounded-lg` border, `my-6` vertical spacing
  - Lists: `pl-6`, `space-y-1`
  - Blockquotes (callouts): styled with left border + background tint per callout type (tip/warning/info)
- **Guide sidebar trigger button:** `size-9` square button, `BookOpen` icon (Lucide), `rounded-md hover:bg-muted`, positioned in top-left above breadcrumb

## Copywriting Contract

| Element | Copy | Notes |
|---------|------|-------|
| Sidebar nav item | `Guide` | Matches existing nav label convention (single noun) |
| Section index page title | `Your Guide` | Role-personalized framing — not "All Guides" |
| Section index subtitle | `Resources for your role. Browse a section to get started.` | Visible below page title when sections exist |
| Empty state heading | `No guides yet` | Shown when user's role has zero sections |
| Empty state body | `No guides have been set up for your role yet. Check back soon.` | No CTA (user cannot create guides in this phase) |
| Section card CTA label | `Open` | On hover/focus — verb only, no object (card is self-descriptive) |
| Section page title | `{Section.title}` | Dynamic — section title from API |
| Page breadcrumb format | `{Section.title} / {Page.title}` | Chevron Right icon (Lucide 12px) as separator |
| Read time display | `~{n} min read` | Displayed in page header metadata row |
| Last updated display | `Updated {relative date}` | e.g. "Updated 3 days ago" — use `date-fns/formatDistanceToNow` |
| Guide sidebar close button aria-label | `Close guide navigation` | Accessibility requirement |
| Guide sidebar open button aria-label | `Open guide navigation` | Accessibility requirement |
| Error state heading | `Could not load this guide` | Shown when API returns error |
| Error state body | `Something went wrong loading the content. Try refreshing the page.` | No destructive action — no confirmation needed |
| Section page empty (no pages) | `No pages in this section yet.` | Shown when section has 0 published pages |

Destructive actions: none in this phase. No confirmation dialogs required.

## Interaction Contract

### Hover States

| Element | Hover Behavior |
|---------|---------------|
| Section index card | BorderBeam activates, MagicCard gradient glow activates, card background tints with section accent at 10% opacity |
| Sidebar page link | `bg-muted text-foreground` (14px transition-colors 150ms) |
| Breadcrumb section link | `underline text-foreground` |

### Loading States

| Context | Behavior |
|---------|---------|
| Section index page | `GuideSectionIndexSkeleton` — 3-column grid of 6 `Skeleton` cards (`h-36 rounded-xl`), animated pulse |
| Section page (page list) | 5 `Skeleton` rows (`h-12 rounded-lg`), spacing `space-y-3` |
| Page reading view | `GuidePageSkeleton` — heading skeleton (`h-7 w-64`), subtitle skeleton (`h-4 w-96`), then 8 text-line skeletons with varying widths |
| Guide sidebar content | Skeleton tree — 2 section headings (`h-4 w-32`) each with 3 page link skeletons (`h-3 w-48`) |

### Active / Selected States

| Element | Active Behavior |
|---------|----------------|
| Active page in guide sidebar | `bg-primary text-primary-foreground rounded-md` — matches existing NavLink active pattern |
| Active section in guide sidebar | Section header bold (weight 600), chevron points down (expanded) |
| Sidebar hamburger button when open | `bg-muted` pressed state |

### Animations

| Element | Animation | Duration | Library |
|---------|-----------|----------|---------|
| BorderBeam on section card | Continuous orbit, `linear`, infinite | 6s | `motion/react` via BorderBeam component |
| MagicCard gradient glow | Follows cursor position on hover | Instant (spring) | `motion/react` via MagicCard component |
| Guide sidebar slide-in | Slide from left | 300ms ease-out | shadcn Sheet (Radix Dialog) |
| Skeleton pulse | `animate-pulse` (CSS) | 2s infinite | Tailwind |
| Section collapse/expand | Height transition | 200ms ease-out | Tailwind `transition-all` |

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Guide sidebar open/close | `aria-label` on trigger button, Sheet uses Radix Dialog ARIA roles |
| Breadcrumb navigation | `<nav aria-label="Breadcrumb">` wrapping `<ol>` with `<li>` items |
| Active page in sidebar | `aria-current="page"` on the active page link |
| Section collapse toggle | `aria-expanded` on section header button |
| Image in prose | `alt` text preserved from Tiptap image node (required in Phase 16 editor) |
| Callout blocks | `role="note"` for tip/info, `role="alert"` for warning |
| Color contrast | All text/background combos use shadcn tokens which pass WCAG AA |
| Keyboard navigation | All sidebar links and section cards keyboard-focusable (native `<a>`, `<button>`) |

### GuideProseRenderer

- Client component (`"use client"`)
- `useEditor({ extensions: [StarterKit, Image, ...calloutExtensions], editable: false, immediatelyRender: false, content: parsedJson })`
- Outer div: `class="prose prose-neutral dark:prose-invert max-w-none text-[16px] leading-[1.75]"`
- Tiptap `<EditorContent>` inside the outer div
- DOMPurify not required (read-only Tiptap instance does not use `dangerouslySetInnerHTML`)

### GuideCalloutBlock (Tiptap custom node extension)

Three variants, all sharing the same base structure:

```
<div role="{note|note|alert}" className="flex gap-3 rounded-lg px-4 py-3 my-4 {variant-bg} border-l-4 {variant-border}">
  <{Icon} className="size-5 shrink-0 mt-0.5 {variant-icon-color}" />
  <div className="text-[14px] leading-[1.5]">{content}</div>
</div>
```

| Variant | Background | Border | Icon | Icon color |
|---------|-----------|--------|------|------------|
| tip | `bg-success/10` | `border-success` | `CheckCircle2` | `text-success` |
| warning | `bg-amber-500/10` | `border-amber-500` | `AlertTriangle` | `text-amber-500` |
| info | `bg-info/10` | `border-info` | `Info` | `text-info` |

### GuideSidebarSheet

- `<Sheet>` from shadcn, `side="left"`, `className="w-[280px] p-0"`
- Header: `px-4 py-3 border-b flex items-center gap-2` — `BookOpen` icon (size-4) + "Guide" label (16px / semibold)
- Close button: `X` icon, top-right, `aria-label="Close guide navigation"`, `size-9 rounded-md hover:bg-muted`
- Body: `<ScrollArea className="flex-1">` wrapping the section tree nav
- Section entry: collapsible `<details>` or controlled state; section icon (16×16, accent color) + title (14px / semibold)
- Page link: `<Link>` with 16px left indent, 14px regular text, active = `bg-primary text-primary-foreground rounded-md`, inactive = `text-muted-foreground hover:bg-muted hover:text-foreground`
