| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline cell padding, badge padding |
| sm | 8px | Compact element spacing, table cell padding |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, dialog body padding |
| xl | 32px | Layout gaps, between page sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top padding |

Exceptions:
- Drag-drop upload zone minimum height: 160px (accommodates icon + primary label + secondary label)

## Interaction Contracts

### Upload Zone

- Default state: dashed border `var(--border)`, `Upload` icon (48px), "Drag & drop your CSV or XLSX file here" primary label, "or click to browse" secondary label in muted color
- Drag-over state: border color switches to `var(--primary)`, background tints to `var(--muted)`, scale transform 1.01
- File accepted state: zone collapses to a compact file chip (filename + size + `X` remove button), "Parse File" button appears below
- Error state (unsupported format): red border + "Only CSV and XLSX files are accepted" inline message

### Preview Table

- Rendered after successful parse only (skeleton during parse)
- Row status column (first): colored dot badge — green for valid, red for invalid, amber for duplicate-candidate
- Invalid cell: red underline on cell text + on hover shows `Tooltip` with exact error (e.g., "Required field", "Invalid email format", "Ingredient not found")
- Editable cell: clicking a cell in an invalid row activates `Input` in place, pressing Enter or clicking away commits the edit and re-validates that row
- Sticky header: column headers remain visible during vertical scroll
- Horizontal scroll: table wrapper `overflow-x: auto` for wide schemas (vendor pricing has 5+ columns)

### "Update existing records" Toggle

- Default: OFF (skip duplicates)
- ON state: amber badge on duplicate-candidate rows changes to "Will update" in info color
- Toggle label: "Update existing records" with `Switch` component; below label show helper text "Matching by name — existing records will be overwritten"

### Import Button

- Label: "Import [N] Records" where N is count of valid rows
- Disabled when: N = 0 (no valid rows), or parse in progress, or import in progress
- Loading state: `Loader2` spin icon + "Importing..." label, button disabled
- On success: button becomes disabled, result summary card appears below table

### Import Result Summary

- Four stat blocks in a horizontal row: "Imported" (green), "Updated" (blue/info), "Skipped" (muted), "Errors" (red)
- Format: large number (text-2xl font-bold) + label below (text-xs text-muted-foreground)
- Below stats: "View import history" link → `/admin/import/history` (if planned) or dismiss
- If Errors > 0: amber alert banner "X rows had errors and were not imported. Fix them inline and re-import."

## States Required Per Feature

### Upload Zone States
1. Default (idle, no file)
2. Drag-over (file hovering over zone)
3. Invalid drag (unsupported file type detected on drag)
4. File accepted (valid file dropped/selected)
5. Parsing (API call in progress)
6. Parse error (server returned error)

### Preview Table Row States
1. Valid (green badge)
2. Invalid (red badge, one or more cells highlighted)
3. Duplicate — will skip (amber badge, toggle OFF)
4. Duplicate — will update (info badge, toggle ON)
5. Editing (one cell has active Input)

### Import Button States
1. Disabled — no valid rows
2. Enabled — N valid rows ready
3. Loading — import in progress
4. Disabled post-success — import complete
