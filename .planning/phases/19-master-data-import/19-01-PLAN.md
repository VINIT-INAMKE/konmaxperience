async findAllForExport(): Promise<any[]> {
  return this.prisma.quest.findMany({
    include: {
      owner: { select: { id: true, name: true } },
      mission: { select: { id: true, title: true } },
      _count: { select: { tasks: true } },
    },

}

- Constructor injects QuestsService
- Map data: `owner?.name` -> owner, `mission?.title` -> mission, `_count.tasks` -> task_count

Both builders: import ExcelJS, writeToBuffer from @fast-csv/format, and ExportBuilder from '../exports.service'. Bold header row on XLSX (`sheet.getRow(1).font = { bold: true }`).
