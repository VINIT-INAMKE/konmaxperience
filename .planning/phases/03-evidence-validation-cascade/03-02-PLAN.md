From backend/prisma/schema.prisma:
```prisma
model Task {
  valid         Boolean  @default(false)
  valid_xp      Int      @default(0)
  verified      Boolean  @default(false)
  xp            Int      @default(25)
  task_type     String   @default("core") // 'core' | 'adhoc' | 'improvement'
  readiness_meter_id String?
  readiness_value    Int  @default(0)
  requires_approval  Boolean @default(true)
}

model TaskReadinessEvent {
  revoked_at DateTime?
  applied    Boolean   @default(true)
  value      Int
}
```

XP calculation rules (from dev spec section 10.2):
- core: task.xp * 1.0
- adhoc: task.xp * 0.7 (rounded down)
- improvement: task.xp * 0.8 (rounded down)

Level thresholds (from dev spec section 10.4):
- < 200 XP: level 1
- < 500 XP: level 2
- < 1000 XP: level 3
- >= 1000 XP: level 4

       b. `recalculateUserXp(userId: string, tx: Prisma.TransactionClient): Promise<void>`
          - Sum valid_xp from all valid tasks owned by userId
          - Derive level: xp < 200 -> 1, < 500 -> 2, < 1000 -> 3, else 4

       c. `recalculateQuestProgress(questId: string | null, tx: Prisma.TransactionClient): Promise<void>`
          - TIGHTENED: count tasks where valid=true (NOT status='done')
          - Core progress: valid core tasks / baseline_task_count
          - Adhoc progress: valid adhoc tasks / total adhoc tasks
          - Combined: (coreValid + validAdhoc * 0.7) / (baseline + totalAdhoc * 0.7)
          - Update quest core_progress_percent, adhoc_progress_percent, progress_percent
          - Do NOT touch quest.status

       d. `recalculateMissionProgress(missionId: string, tx: Prisma.TransactionClient): Promise<void>`
          - TIGHTENED: count tasks where valid=true (NOT status='done')
          - progress = validCount / totalCount * 100
          - Do NOT touch mission.status

       e. `applyReadinessFromTask(taskId: string, isValid: boolean, tx: Prisma.TransactionClient): Promise<void>`
          - If task has no readiness_meter_id, return
          - If isValid=true: check for existing active event (revoked_at: null) — if exists, skip (idempotent); otherwise create new TaskReadinessEvent
          - If isValid=false: revoke all active events for this task (set revoked_at=new Date(), applied=false)
          - ALWAYS recompute meter current_value from all active events (revoked_at: null) — sum values, cap at 100

       f. `validateTask(taskId: string, tx: Prisma.TransactionClient): Promise<{ valid: boolean; valid_xp: number }>`
          - Fetch task with evidence and approvals includes
          - hasApprovedEvidence = evidence.some(e => e.approval_status === 'approved')
          - approvalsSatisfied = task.requires_approval ? task.approvals.every(a => a.status === 'approved') : true
          - isValid = task.status === 'done' && hasApprovedEvidence && approvalsSatisfied
          - validXp = isValid ? calculateEffectiveXp(task) : 0
          - Update task: valid=isValid, valid_xp=validXp, verified=isValid (auto-set, no manual step)
          - Call recalculateUserXp, recalculateQuestProgress, recalculateMissionProgress, applyReadinessFromTask
          - Return { valid: isValid, valid_xp: validXp }

       g. `approveEvidence(evidenceId: string, reviewerId: string): Promise<{ valid: boolean; valid_xp: number }>`
          - Wrap EVERYTHING in prisma.$transaction(async (tx) => { ... })

          - Update evidence: approval_status='approved', reviewed_by=reviewerId, reviewed_at=new Date()
          - Call validateTask(evidence.task_id, tx) inside the same transaction
          - Return the validateTask result
