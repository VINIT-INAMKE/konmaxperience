# Phase 17 — UI Design Contract: Search, Preview, and Content Seeding

> Visual and interaction contract for the Cmd+K search overlay and the admin preview-as-role dropdown.
> Content seeding (SEED-01 through SEED-04) is a backend/data task — no UI components required for it.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

---

## Scope

Two UI surfaces in this phase:

1. **Cmd+K Search Overlay** — global full-text search across visible guide pages (READ-03). Accessible from anywhere inside `/guide/*` routes. Keyboard-triggered (`Cmd+K` / `Ctrl+K`) and optionally via a search trigger button in the guide sidebar.
2. **Preview-as-Role Dropdown** — admin-only role selector on the `/guide` index page that filters the section grid to match any role's view exactly (READ-04). Frontend-only filtering; no backend role-spoofing.

Content seeding (SEED-01–04) has no UI component surface. It is a Prisma seed expansion — no UI-SPEC entries required.

### Search Overlay Layout

The search overlay uses `CommandDialog` from shadcn (wraps `Dialog` + `Command`). It is centered, positioned at `top-[20%]` via CSS override on the Dialog content.

```
CommandDialog (max-w-[560px], centered horizontally, top-20%)
├── CommandInput (search input, 16px, placeholder: "Search guides...", leading Search icon 16px)
├── CommandList (max-h-[360px] overflow-y-auto)
│   ├── CommandEmpty — "No matching guide pages found."
│   ├── CommandGroup label: "{n} results" (14px / text-muted-foreground) — only shown when results exist
│   └── CommandItem × N — one per result
│       ├── FileText icon (size-4, text-muted-foreground, shrink-0)
│       ├── [content column, flex-1 min-w-0]
│       │   ├── Page title (14px / weight 600 / truncate)
│       │   └── Snippet (13px / text-muted-foreground / line-clamp-2) — match highlighted in accent color
│       └── Section badge (Badge variant="secondary", 12px, truncate, max-w-[120px])
└── [footer bar] — "Esc to close" hint (11px / text-muted-foreground) + Kbd badge
```

Footer bar: `flex items-center justify-between px-3 py-2 border-t text-[11px] text-muted-foreground bg-muted/30`
- Left: `↑↓ to navigate · ↵ to open`
- Right: `Esc to close` with `<Kbd>Esc</Kbd>` badge

`Kbd` badge styling: `inline-flex items-center px-2 py-1 rounded border bg-muted text-[11px] font-mono font-medium`

The role selector is placed in the `/guide` page header area, visible only when the logged-in user has `FOUNDER_ADMIN` or `TECH_LEAD` role code (these are the admin-level roles per existing RBAC).

## Interaction Contract

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd+K` (macOS) / `Ctrl+K` (Win/Linux) | Open `GuideSearchOverlay` |
| `Esc` | Close overlay, clear query |
| `ArrowUp` / `ArrowDown` | Navigate result items (handled by `cmdk` library natively) |
| `Enter` | Navigate to selected result page — `router.push('/guide/{sectionSlug}/{pageSlug}')` |

Keyboard listener: mounted in `GuideSearchOverlay` via `useEffect`. Listener attached to `document`, `keydown` event. Captures `(e.metaKey || e.ctrlKey) && e.key === 'k'`. Guard: only fires when not typing inside another input/textarea.

### Search Behavior

- Query is debounced 300ms after last keystroke before firing API call
- Minimum query length: 2 characters — no API call for 0–1 characters; show initial empty state hint instead
- API call: `GET /guide/search?q={query}` — backend returns results pre-filtered by caller's role
- Results include: `pageId`, `pageTitle`, `pageSlug`, `sectionTitle`, `sectionSlug`, `snippet` (plain text, max 200 chars, matched substring denoted by server)
- Loading state: `CommandList` shows 3 skeleton rows (`h-10 rounded-md animate-pulse`) while awaiting response
- On result click: `router.push('/guide/{sectionSlug}/{pageSlug}')` + overlay closes

### Preview-as-Role Behavior

- Role selector visible only when `authStore.roleCode === 'FOUNDER_ADMIN' || authStore.roleCode === 'TECH_LEAD'`
- On role select: `previewRole` state set to selected `RoleCode`
- Guide index re-filters `sections` data client-side: `sections.filter(s => s.role_codes.includes(previewRole))`
- No new API call required — guide index already fetches all sections (admin sees all)
- `GuidePreviewBanner` renders below the page header while `previewRole !== null`
- On "Back to your view" click: `previewRole` state reset to `null`, banner unmounts, section grid reverts to role-filtered view
- `previewRole` state is local to the `/guide` page component — does NOT persist across navigation or page reloads

### Loading States

| Context | Behavior |
|---------|---------|
| Search results loading (query fired) | 3 skeleton rows inside `CommandList`: `h-10 rounded-md bg-muted animate-pulse mx-2 my-1` |
| Search overlay opening | `CommandDialog` opens instantly — no animation delay; `CommandInput` auto-focused |
| Role selector loading initial data | Not applicable — section data already fetched by the guide index page |

### Hover States

| Element | Hover Behavior |
|---------|---------------|
| Search result item (`CommandItem`) | `bg-muted` background — inherited from `cmdk` `data-[selected]` styling |
| Search trigger button (page header) | `bg-muted` background (`Button variant="outline"` hover) |
| Search trigger button (sidebar) | `bg-muted` background (`Button variant="ghost"` hover) |
| Preview banner "Back to your view" | `text-amber-900 dark:text-amber-300` — darker amber on hover |

### Animations

| Element | Animation | Duration | Library |
|---------|-----------|----------|---------|
| Search overlay open | Fade in + zoom in 95% (`animate-in fade-in-0 zoom-in-95`) | 150ms | shadcn Dialog (Radix) |
| Search overlay close | Fade out + zoom out 95% (`animate-out fade-out-0 zoom-out-95`) | 100ms | shadcn Dialog (Radix) |

| Preview banner appear | `animate-in slide-in-from-top-2 fade-in-0` | 200ms | Tailwind `animate-in` |
| Preview banner dismiss | `animate-out slide-out-to-top-2 fade-out-0` | 150ms | Tailwind `animate-out` |

| Requirement | Implementation |

## Component-by-Component Spec

### GuideSearchOverlay

```
"use client"
// Mounted once inside the guide layout (or guide index page).
// Registers Cmd+K / Ctrl+K listener on document.
// Manages open/close state.

<CommandDialog open={open} onOpenChange={setOpen} aria-label="Search guides">
  <CommandInput
    placeholder="Search guides..."
    value={query}
    onValueChange={setQuery}
  />
  <CommandList>
    {isLoading && <SearchSkeletonRows />}
    {!isLoading && !query && (
      <CommandEmpty>Type to search guide pages.</CommandEmpty>
    )}
    {!isLoading && query.length >= 2 && results.length === 0 && (
      <CommandEmpty>No matching guide pages found.</CommandEmpty>
    )}
    {!isLoading && results.length > 0 && (
      <CommandGroup heading={`${results.length} result${results.length !== 1 ? 's' : ''}`}>
        {results.map(r => (
          <GuideSearchResultItem
            key={r.pageId}
            result={r}
            onSelect={() => { router.push(`/guide/${r.sectionSlug}/${r.pageSlug}`); setOpen(false); }}
          />
        ))}
      </CommandGroup>
    )}
  </CommandList>
  <div className="flex items-center justify-between px-3 py-2 border-t text-[11px] text-muted-foreground bg-muted/30">
    <span>↑↓ to navigate · ↵ to open</span>
    <span>Esc <Kbd className="inline-flex items-center px-2 py-1 rounded border bg-muted text-[11px] font-mono font-medium">Esc</Kbd> to close</span>
  </div>
</CommandDialog>
```

Query debounce: 300ms. Minimum 2 chars before firing. Uses `useQuery` with `enabled: query.length >= 2`. Query key: `['guide', 'search', query]`.

### GuideSearchResultItem

