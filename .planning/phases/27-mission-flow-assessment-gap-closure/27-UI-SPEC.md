## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge inner padding |
| sm | 8px | Compact row padding (`px-2 py-1.5`), badge row gaps (`gap-1.5`) |
| md | 16px | Default element spacing (`gap-4`, `px-4`) |
| lg | 24px | Section spacing (`space-y-6`, `gap-6`) |
| xl | 32px | Dashboard section breaks (`space-y-8`) |
| 2xl | 48px | Major page-level breaks (`pt-8`) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Widget card content uses `pt-4` (16px) for top padding — consistent with existing widget pattern
- Section labels use `space-y-5` (20px) — inherited from admin dashboard zone pattern
- Touch targets for interactive rows: min 36px height via `py-1.5` + `text-sm` line-height — matches existing widget rows

---

## Typography

All sizes are derived from the established codebase pattern.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 | Row content, list items, widget body text |
| Label | 12px (`text-xs`) | 400 (regular) | 1.5 | Metadata, timestamps, secondary info, section sublabels |
| Heading | 14px (`text-sm`) | 700 (bold) | 1.2 | Widget titles (`font-bold`), section headers |
| Display | 24px (`text-2xl`) | 700 (bold) | 1.2 | Page title "Mission Control" / "My Dashboard" — existing pattern |

Micro text: 10px (`text-[10px]`) at weight 400 — badge labels only, not body copy.

## Color

All tokens are OKLCH CSS variables. Use `var(--token)` wrapper in all Tailwind classes (per project rule: `bg-[var(--token)]` not `bg-[--token]`).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` | Page backgrounds, widget card backgrounds |
| Secondary (30%) | `var(--card)` / `var(--muted)` | Card surfaces, row hover states (`hover:bg-muted`), sidebar |
| Accent (10%) | `var(--primary)` | Readiness gauge primary color, active state indicators |
| Destructive | `var(--destructive)` | Blocked task border (`border-l-destructive`), overdue dates, blocker badges |

Semantic colors in use (sourced from existing components — do not add new colors):

| Token | Usage in this phase |
|-------|---------------------|
| `text-emerald-500` / `text-green-500` | Quest completion events in activity feed, validated task icons |
| `text-amber-500` / `text-amber-600` | Active quest badge, ad-hoc task badge, "Today's Focus" overdue highlight when status=active |
| `text-blue-500` | Readiness impact badges (`+N MetricName`) on kanban card |
| `text-muted-foreground` | Timestamps, secondary labels, metadata, "View all" links |

Accent (`var(--primary)`) is reserved for: readiness gauge primary ring, primary Button fills.

## Component Inventory

New components required for this phase:

### AdminActivityFeedWidget
- Pattern: mirrors `AdminPendingApprovalsWidget` (Card + CardHeader + CardTitle + CardAction + CardContent)
- Item row: icon (12px Lucide) + event description (`text-sm`) + timestamp (`text-xs text-muted-foreground`, relative time via `date-fns formatDistanceToNow`)
- Max 5 items on widget; "View all" link to `/activity` at bottom-right
- Empty state: `ActivityIcon` (16px, `text-muted-foreground/30`) + "No mission activity yet" heading + "Complete and validate tasks to see the feed populate." body
- Loading: 3 rows of `animate-pulse` skeleton (`h-4 w-full rounded bg-muted`)
- Event type icons: CheckCircle2 (validation), TrendingUp (readiness movement), ShieldX → Unlock (blocker resolved), Trophy (quest complete)
- Compact badge per event type: `text-[10px]` outline badge, matches existing widget badge pattern
- Placed in admin dashboard "Status" zone, below DashboardReadinessStrip

### AdminTeamContributionWidget
- Pattern: Card + compact per-role table rows (role name + tasks completed + validated + blocked + readiness delta)
- Time scope selector: shadcn Select ("This Week" / "This Month" / "This Mission") — default "This Mission" (D-11)
- Role name only, no person name (D-12) — e.g., "Backend Lead", "Procurement Lead"
- Per-role row: `flex items-center gap-3 text-sm px-2 py-1.5 rounded-md hover:bg-muted`
- Readiness delta: `text-blue-500` with `TrendingUp` icon (same pattern as kanban card readiness badge)
- "View details" link routes to `/team-contribution` full page
- Empty state: "No contributions recorded yet for this period."
- Loading: 4 rows of pulse skeleton
- Placed in admin dashboard "Intelligence" zone, alongside DashboardLeaderboardPreview

### TodaysFocusSection (non-admin dashboard)
- Inserted above "My Tasks" card in `RoleDashboardSections`
- Section heading: `text-sm font-bold` ("Today's Focus")
- Max 5 items filtered from existing `/tasks` response — no new endpoint (D-14)
- Sort order: overdue first (red `text-destructive` due date) → due today (amber date) → active quest tasks by priority
- Item row: task title (`text-sm flex-1 truncate`) + quest context (`text-xs text-muted-foreground truncate max-w-[120px]`) + due date badge
- Overdue items: due date shows `text-destructive` + "· Overdue" suffix (inherits existing pattern from `TaskKanbanCard`)
- Conditionally rendered: only shown if there are overdue or due-today tasks. Hidden entirely when no urgent tasks.
- No empty state needed — section is hidden when empty

### ActivityFeedPage (`/activity`)
- Full page list of activity feed items (unlimited, paginated if needed)
- Layout: standard ops page with `text-2xl font-bold` heading "Activity Feed"
- Filter bar: event type filter (Select) + date range (not in scope for this phase — plain list is sufficient)
- Each item: Card row with icon + description + timestamp + optional link to related entity

### TeamContributionPage (`/team-contribution`)
- Full page version of the widget (admin-only)
- Per-role expandable rows showing task breakdown
- Time scope selector (same Select as widget, persisted in URL param)
- Layout: single column, full-width table or card stack

## Layout Patterns

### Admin Dashboard Zones (additive — do not restructure existing zones)

```
Action Required zone (existing): AdminPendingApprovalsWidget | AdminBlockersWidget | AdminAdHocInjectorWidget
Status zone (existing + new):    DashboardReadinessStrip | AdminRecentDecisionsWidget | [NEW] AdminActivityFeedWidget
Intelligence zone (existing + new): DashboardLeaderboardPreview (lg:col-span-3) | DashboardLowStockAlert (lg:col-span-2) | [NEW] AdminTeamContributionWidget below leaderboard
```

### Task Kanban Card — readiness badge update
- Existing: `+{N}` badge with `TrendingUp` icon, `text-blue-500 border-blue-500/30`
- Updated: `+{N} {MetricName}` where MetricName is truncated to 12 chars max + ellipsis if longer
- No layout change — same badge slot, same color, longer label only

### Task List View — mission/quest columns
- Two new `TableHead` columns: "Quest" and "Mission" (collapsible on mobile via `hidden md:table-cell`)
- Cell content: `text-xs text-muted-foreground truncate max-w-[140px]` — link to quest/mission detail on hover
- Columns appended before the "Actions" column

### Task Detail Page — breadcrumb chain
- Replaces existing back arrow link (`ArrowLeft`)
- New: `Mission Name → Quest Name → Task Title` rendered as:
  - Mission: `Link` to `/boards/missions` (or `/missions/{id}`)
  - Arrow separator: `ChevronRight` icon 12px `text-muted-foreground`
  - Quest: `Link` to quest detail
  - Arrow separator
  - Task title: plain text (current page)
- Typography: `text-sm text-muted-foreground` for links, `text-sm font-medium` for current page title
- Falls back to plain "Back to Tasks" `ArrowLeft` link if task has no quest (adhoc tasks)

### Task Detail Page — Linked Resources section
- Appears below `EvidenceSection`, above page end
- Section heading: `text-sm font-bold` ("Linked Resources")
- Two sub-lists: "Purchase Orders" and "Assets"
- Each linked item: `flex items-center gap-2 text-sm` + `Badge variant="outline"` for type label + `Link` to PO/Asset detail
- Empty: section hidden entirely when no linked POs or Assets
- PO link/edit form: optional "Link to task" `Select` dropdown on PO create/edit form — same shadcn Select pattern as existing form fields

### Validation Toast — readiness impact
- Existing: `toast.success("Task validated! +{N} XP")`
- Updated: `toast.success("Task validated! +{N} XP · +{M} {MeterName}")` when `task.readiness_meter_id` is set
- "·" is a middle dot separator (U+00B7), same character used in existing overdue label
- If no readiness meter linked: existing toast format unchanged

## Interaction States

| Component | State | Behavior |
|-----------|-------|----------|
| AdminActivityFeedWidget | Loading | 3-row pulse skeleton, identical to AdminPendingApprovalsWidget skeleton |
| AdminActivityFeedWidget | Empty | Icon + heading + body, identical structure to AdminPendingApprovalsWidget empty |
| AdminActivityFeedWidget | Error | Inline `text-sm text-muted-foreground` error message, no throw |
| AdminTeamContributionWidget | Loading | 4-row pulse skeleton |
| AdminTeamContributionWidget | Scope change | React Query refetch on Select change, skeleton shown during refetch |
| TodaysFocusSection | No urgent tasks | Section hidden entirely (no render) |
| TaskKanbanCard readiness badge | Meter name present | Shows "+{N} {MeterName}" truncated to 12 chars |
| TaskKanbanCard readiness badge | No meter | Shows "+{N}" (existing behavior unchanged) |
| Breadcrumb links | Quest/Mission missing | Falls back to "ArrowLeft Back to Tasks" (adhoc tasks have no quest) |
| Linked Resources | No links | Section not rendered |
| PO form "Link to Task" | Dropdown | shadcn Select with searchable task list, placeholder "No linked task" |
