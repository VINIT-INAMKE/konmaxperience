## Spacing Scale

Declared values (multiples of 4 only). Identical to Phase 15 — continuity required.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Toolbar button icon gaps, toolbar divider spacing |
| sm | 8px | Toolbar button internal padding, section list item gaps |
| md | 16px | Sheet form field spacing, editor toolbar height internal padding |
| lg | 24px | Sheet content padding, editor container outer padding |
| xl | 32px | Admin page header to content gap |
| 2xl | 48px | Major vertical section breaks on admin list page |
| 3xl | 64px | Editor page outer padding (top of editor area below toolbar) |

Exceptions:
- Toolbar button touch target: 32px × 32px (`size-8` in Tailwind) — desktop-only admin UI; 32px is appropriate for pointer use
- Toolbar button groups separated by `Separator` (`h-5`, 1px vertical line) with `mx-1` gap on each side (4px)
- Editor area: no max-width constraint — full available width within ops layout minus sidebar
- Sheet (section/page forms): `max-w-[500px]` — matches existing VendorForm, ZoneForm, EventForm pattern
- Bubble menu: floats above selected text, `z-50`, with `4px` gap from the selection baseline

## Layout Contract

### Route Structure

| Route | Page | Layout |
|-------|------|--------|
| `/admin/guide` | Guide management — section list with expand-to-pages, inline actions | Ops layout (existing sidebar), `space-y-6` content area |
| `/admin/guide/pages/[id]` | Full Tiptap editor for a single guide page | Ops layout (existing sidebar), editor occupies full remaining width |

### Admin Guide Management Page (`/admin/guide`)

- **Page header:** Same pattern as `/admin/users` — `flex items-center justify-between` with `<h1>` (24px / semibold) on left, "Add Section" `<Button>` on right
- **Page title:** `Guide Management`
- **Section list container:** `space-y-3` — one card per section
- **Section card anatomy:**
  - Collapsible — click section row to expand/collapse page list
  - Row layout: `flex items-center gap-3 px-4 py-3 rounded-xl border bg-card hover:bg-muted/50 cursor-pointer`
  - Left: DragHandle icon (`GripVertical`, size-4, `text-muted-foreground`) — reorder affordance (up/down arrow buttons on hover as Claude's discretion resolved below)
  - Section icon: `DynamicIcon` component (reused from Phase 15), size-5, colored with `accent_color`
  - Section title: 16px / semibold, `text-foreground`
  - Role badges: compact Badge list (one per role, `variant="secondary"`, 12px text), max 3 visible then `+N more`
  - Status badge: draft (amber) or published (green) — 14px
  - Page count: `{n} pages` (14px / `text-muted-foreground`)
  - Right: actions row — Edit button (pencil icon), Delete button (trash icon, destructive color), ChevronDown/Up toggle
  - Collapsed: shows section row only
  - Expanded: section row + indented page list below (16px left indent from section icon)
- **Page list item (inside expanded section):**
  - `flex items-center gap-2 px-4 py-2 hover:bg-muted/50 rounded-lg`
  - File icon (`FileText`, size-4, `text-muted-foreground`)
  - Page title (14px / regular)
  - Status badge (draft/published, same colors as section)
  - Right: Edit button (links to `/admin/guide/pages/[id]`), Delete button (dropdown or direct with confirmation)
  - Sort order drag handle (`GripVertical`, size-4) for reordering within section
- **Reorder approach (Claude's discretion):** Up/Down arrow icon buttons on hover — `ChevronUp` and `ChevronDown` (size-4, `text-muted-foreground`) — simpler than drag-and-drop, no library dependency, works on touch screens used by kitchen staff. Arrow buttons call PATCH sort_order endpoint directly.

### Section Form (Sheet — create/edit section)

  - Role multi-select: checkbox group, one checkbox per role code, label uses `ROLE_DISPLAY_NAMES`. All roles listed. Label: "Visible to roles"
- `SheetFooter`: Cancel button (`variant="ghost"`) + Save button (`variant="default"`, label "Save Section")

### Editor Page (`/admin/guide/pages/[id]`)

- **Overall layout:** Full ops layout with existing sidebar. Editor fills remaining width. No inner max-width on the editor container — admin benefits from wider writing area.
- **Editor page header bar:** `flex items-center justify-between px-6 py-3 border-b bg-card sticky top-0 z-10`
  - Left: Back link (`ArrowLeft` icon + "Guide Management" text, 14px, `text-muted-foreground hover:text-foreground`)
  - Center: Page title input (`<input type="text">` styled as `text-[20px] font-semibold bg-transparent border-none outline-none w-full max-w-[600px] placeholder:text-muted-foreground`)
  - Right: autosave indicator + Unpublish/Publish controls (see Publish Bar section)
- **Fixed toolbar:** `flex items-center gap-1 px-4 py-2 border-b bg-muted/50 sticky top-[49px] z-10` (below the page header bar, also sticky)
  - Groups separated by `Separator` (vertical, `h-5 mx-1`):
    - Group 1 — Block type: Heading H2 (`H2` text label, size-8 button), Heading H3 (`H3`), Heading H4 (`H4`), Paragraph (`Pilcrow` icon)
    - Group 2 — Lists: Bullet list (`List` icon), Ordered list (`ListOrdered` icon)
    - Group 3 — Media/blocks: Image upload (`ImagePlus` icon), Callout — Tip (`CheckCircle2` icon, `text-success`), Callout — Warning (`AlertTriangle` icon, `text-amber-500`), Callout — Info (`Info` icon, `text-info`)
  - All toolbar buttons: `size-8 rounded-md` with active/inactive states per color contract above
  - Toolbar is `dynamic({ ssr: false })` — part of the editor component, not server-rendered
- **Bubble menu (floating, on text selection):** Appears above selected text, `z-50`, `bg-popover border rounded-lg shadow-md flex items-center gap-1 p-1`
  - Bold (`Bold` icon), Italic (`Italic` icon), Underline (`Underline` icon)
  - Separator
  - Link (`Link2` icon — opens a small inline input to set href)
  - All buttons: `size-7 rounded-md` (compact for floating context)
  - Animation: fade in 150ms, `animate-in fade-in-0 zoom-in-95`
- **Editor content area:** `px-6 py-8 min-h-[calc(100vh-120px)]` — tall enough to feel spacious, scrollable
- **Draft banner:** When `status === 'draft'`, show `bg-amber-500/10 border border-amber-500/20 rounded-lg px-4 py-2 mb-4 flex items-center gap-2 text-[14px] text-amber-600` with `AlertTriangle` icon + "This page is a draft. Only admins can see it."

### Publish Bar (right side of editor page header)

- Autosave indicator: `text-[14px] text-muted-foreground` — states: "Saving..." (with `Loader2` spin, 14px), "Saved" (with `Check` icon, `text-success`), "Unsaved changes" (with `Circle` icon, `text-amber-500`)
- If `status === 'draft'`: "Publish" button — `variant="default"` with shimmer/gradient border via brand accent — label "Publish"
- If `status === 'published'`: "Unpublish" button — `variant="outline"` with `text-muted-foreground` — label "Unpublish", plus a `Published` badge (green, 14px) to the left of the button
- "Publish" button is visually distinct from the autosave indicator — clear spatial separation

## Interaction Contract

### Toolbar State

| Element | State | Visual |
|---------|-------|--------|
| Bold button | When cursor is in bold text | `bg-primary text-primary-foreground rounded-md` |
| Heading H2 button | When cursor is in H2 block | `bg-primary text-primary-foreground rounded-md` |
| All toolbar format buttons | Inactive | `text-foreground hover:bg-muted rounded-md` |
| All toolbar format buttons | Disabled (no editor focus) | `opacity-40 cursor-not-allowed` |
| Image upload button | During upload | `opacity-60 pointer-events-none` — prevents double-click |

### Image Upload Interaction (D-04, D-05)

Three upload paths — all converge on the same `GuideImageUploadHandler` utility:

1. **Toolbar button:** Click `ImagePlus` → file picker (`accept="image/jpeg,image/png,image/webp"`) → validate → upload
2. **Drag-drop:** Drop image file onto editor area → validate → upload
3. **Paste:** Paste image from clipboard → validate → upload

Upload feedback sequence per D-05:
- Insert a placeholder image node immediately: `<img src="" style="filter: blur(4px); opacity: 0.5" />` with a `UploadProgress` overlay (`Progress` bar from shadcn, `bg-primary h-1 rounded-full`)
- Upload to R2 via presign URL
- On success: replace placeholder with final R2 URL — blur and overlay removed, image renders sharp
- On failure: remove placeholder node, fire Sonner `toast.error(...)` with error copy

### Autosave Behavior (D-14)

- Debounce: 5-second delay after last editor change (`onUpdate` event)
- Change detection: compare SHA-256 of `editor.getHTML()` to last saved hash — skip save if identical
- On save trigger: PATCH `/guide/pages/:id` with `{ content, title }` — both fields in one request
- Autosave indicator transitions: unsaved → saving (during PATCH) → saved (on 200 response)
- Saved indicator clears to neutral (no text) after 3 seconds post-save

### Unsaved Changes Warning (D-16)

- Track `isDirty` state: true when editor content or title differs from last persisted values
- On route change (Next.js router event) with `isDirty: true`: trigger browser `beforeunload` → native dialog
- On successful autosave or manual publish: `isDirty = false`

### Bubble Menu Behavior

- Appears when text selection is non-empty
- Positioned: 4px above the top of the selection (Tiptap `BubbleMenu` default positioning)
- Disappears: immediately on cursor click (empty selection)
- Animation: `animate-in fade-in-0 zoom-in-95 duration-150`

### Reorder Interaction (up/down arrows)

- Up (`ChevronUp`) and Down (`ChevronDown`) arrows visible on section card hover
- Arrow buttons call PATCH endpoint with new sort_order (swap adjacent sort_orders)
- Top item: Up arrow `opacity-30 cursor-not-allowed`
- Bottom item: Down arrow `opacity-30 cursor-not-allowed`
- Same pattern for page reorder within a section

## Tiptap Editor Configuration

The editor uses `shouldRerenderOnTransaction: false` per PITFALLS.md Pitfall 6. Full extension list:

```
useEditor({
  extensions: [
    StarterKit,           // heading h2/h3/h4, bold, italic, underline, lists, history (undoRedo in v3)
    Image,                // @tiptap/extension-image — renders saved R2 image nodes
    CalloutExtension,     // reused from GuideCalloutBlock.tsx — tip/warning/info callout nodes
    Placeholder.configure({ placeholder: 'Start writing your guide page...' }),
    Typography,           // smart quotes, em-dashes — zero config
  ],
  immediatelyRender: false,
  shouldRerenderOnTransaction: false,
  editable: true,
  content: parsedContent,
  onUpdate: ({ editor }) => {
    // debounced autosave trigger (5s debounce + hash check)
  },
})
```

Toolbar active state: driven by `editor.isActive('bold')`, `editor.isActive('heading', { level: 2 })`, etc. — NOT React state. This avoids triggering React re-renders for toolbar state changes.

Dynamic import at page level:
```tsx
const GuideEditorClient = dynamic(
  () => import('@/components/ops/guide/admin/GuideEditorClient'),
  { ssr: false }
)
```
