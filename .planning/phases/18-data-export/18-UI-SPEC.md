## Spacing Scale

Declared values (multiples of 4 only). Identical to Phase 15/16 baseline — continuity required.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, format-selector radio gap |
| sm | 8px | Export button label/icon gap, dialog filter field internal spacing |
| md | 16px | Dialog section spacing, history table cell padding, export button outer padding |
| lg | 24px | Dialog content padding, page section gaps |
| xl | 32px | Admin exports page header-to-content gap |
| 2xl | 48px | Major section breaks on exports history page |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Export button height: 36px (`h-9`) — matches the row-level button size used across operations pages (inventory `StockAdjustmentSheet` trigger, orders filter bar)
- Export dialog max-width: 480px — compact form, no full-panel sheet needed
- History table row height: auto (content-driven, minimum 48px per row)
- Toast notification: Sonner default sizing (not overridden)

## Typography

All values inherited from Phase 15/16 system baseline. No changes for this phase.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body / UI text | 16px | 400 (regular) | 1.5 | Dialog body text, table cell content |
| Label / metadata | 14px | 400 (regular) | 1.5 | Export button label, filter field labels, table column headers, file size in history, format badge, format selector sub-labels, filters summary, date range labels |
| Heading (page/dialog title) | 24px | 600 (semibold) | 1.2 | Admin exports page `<h1>`, Dialog `DialogTitle` |

Final type scale: **14, 16, 24px** — 3 sizes, 2 weights (400, 600). Consistent with Phase 15/16.

The previous draft included 12px and 13px classes (`text-[12px]`, `text-[13px]`) in component snippets for format sub-labels, active filters summary, and format badge. These are all promoted to `text-sm` (14px) to stay within the 3-size constraint.

Font: `Geist Sans` (`--font-sans`) throughout. No secondary display font.

### Export Button (on data pages)

Added to the existing page header filter bar of every data page that supports export:
- Position: rightmost element in the filter bar row (`flex items-end gap-3 flex-wrap` — matches existing orders/inventory filter bar layout)
- Component: `<Button variant="outline" size="sm">` — `h-9`, `variant="outline"` keeps visual weight below the page's primary actions
- Anatomy: `<FileDown className="size-4 mr-2" />` + label `"Export"`
- Icon: `FileDown` (Lucide) — communicates file download affordance
- On click: opens `ExportDialog` (Dialog, not Sheet — compact form, not a full side panel)
- Loading state: button shows `<Loader2 className="size-4 animate-spin mr-2" />` + `"Exporting..."` while export is generating, `disabled` during this state

Affected data pages (one export button each):
`/pos/orders`, `/operations/inventory`, `/intelligence/analytics`, `/operations/purchase-orders`, `/operations/recipes`, `/operations/ingredients`, `/operations/vendors`, `/operations/menu`, `/operations/feedback`, `/operations/events`, `/operations/kitchen/kds` (waste), `/tasks/[id]` summary (not per-task), `/leaderboard`

### Export Dialog (`ExportDialog`)

shadcn `Dialog` (not `Sheet`) — compact interaction, not a side panel form.

- `DialogContent`: `max-w-[480px] w-full`
- `DialogHeader`:
  - `DialogTitle`: `"Export {Report Name}"` — e.g. `"Export Orders"`, `"Export Inventory"` (24px / semibold)
  - `DialogDescription`: `"Download a snapshot of {what is included, e.g. filtered orders} as CSV or XLSX."` (14px / `text-muted-foreground`)
- Dialog body: `space-y-4 py-4`
  - **Format selector** (always shown): Two card-style radio options side by side in `grid grid-cols-2 gap-3`
    - Each option: `rounded-lg border-2 p-3 cursor-pointer flex items-center gap-2 transition-colors`
    - Inactive: `border-border hover:border-muted-foreground/40 bg-background`
    - Active/selected: `border-primary bg-primary/5`
    - CSV option: `<FileText className="size-4 text-muted-foreground" />` + `"CSV"` (14px / semibold) + `"Universal"` sub-label (`text-sm text-muted-foreground`)
    - XLSX option: `<FileSpreadsheet className="size-4 text-muted-foreground" />` + `"XLSX"` (14px / semibold) + `"Formatted"` sub-label (`text-sm text-muted-foreground`)
    - Default selection: XLSX
  - **Date range** (time-series exports only — orders, waste, stock movements, POs): Two `<Input type="date">` fields side by side in `grid grid-cols-2 gap-3`
    - Labels: `"From"` and `"To"` (`text-sm font-semibold text-muted-foreground`) above each input — matching orders page filter bar label convention
    - Default values: carry over current page filter state (per D-17)
    - Not shown for master data exports (ingredients, vendors, recipes, menu) per D-20
  - **Active filters summary** (optional, shown if non-default filters are active): `text-sm text-muted-foreground bg-muted/50 rounded-lg px-3 py-2` — e.g. `"Includes: Channel: Dine-in · Status: Completed"`
- `DialogFooter`: `flex items-center justify-end gap-2`
  - Discard: `<Button variant="ghost">Discard</Button>`
  - Export: `<Button variant="default">Export</Button>` — becomes `<Button disabled><Loader2 className="size-4 animate-spin mr-2" />Generating...</Button>` while generating

### Admin Exports Page (`/admin/exports`)

Matches `/admin/users` layout pattern exactly.

- **Page header:** `flex items-center justify-between`
  - Left: `<h1 className="text-2xl font-bold">Exports</h1>` + subtitle below (14px / `text-muted-foreground`)
  - Right: No primary CTA — exports are triggered from data pages, not from this page
- **Filter bar:** `flex items-center gap-3 flex-wrap` — filter by report type (`Select`) and date range (two date inputs)
  - Report type select: `"All report types"` placeholder, lists all 22 report types in alphabetical groups
  - Date range: `"From"` and `"To"` date inputs (same style as orders/inventory pages)
- **History table:**
  - Column headers: `Report Type` | `Format` | `Filters Applied` | `File Size` | `Generated By` | `Generated At` | `Status` | (empty — actions)
  - All columns 14px / `text-muted-foreground` in `TableHead`
  - Row pattern matches `/admin/users` table: `TableRow className="hover:bg-muted/50"`
  - `Report Type`: 14px / regular, e.g. `"Orders"`, `"Inventory Levels"`
  - `Format`: Badge — CSV: `variant="secondary"`, XLSX: `variant="secondary"` with `FileSpreadsheet` icon prefix; badge text at `text-sm`
  - `Filters Applied`: 14px / `text-muted-foreground`, truncated at 40 chars with ellipsis, full detail in tooltip (`TooltipContent`) on hover
  - `File Size`: 14px / `text-muted-foreground`, formatted as `"124 KB"` or `"2.3 MB"`
  - `Generated By`: 14px / `text-muted-foreground`, display name from `ExportRecord.generatedBy`
  - `Generated At`: 14px / `text-muted-foreground`, relative time — `"3 hours ago"` using `date-fns/formatDistanceToNow`
  - `Status`: Badge per status colors above (Completed / Generating / Failed)
  - Actions column (rightmost, `w-[80px]`): `<Button variant="ghost" size="icon">` with `<Download className="size-4" />` wrapped in a `Tooltip` — tooltip text `"Re-download"` appears on hover; only shown and enabled when status is `Completed`; disabled+`opacity-40` when Generating; hidden when Failed
- **Empty state**: Shown when no export history exists (see Copywriting)
- **Pagination**: Not needed — 22 report types × small team. Show all records, sorted by `Generated At` descending.

## Interaction Contract

### Export Flow (end-to-end)

1. User clicks `Export` button on a data page
2. `ExportDialog` opens (Dialog) — format defaults to XLSX, date range defaults to current page filter state
3. User adjusts format or date range if desired
4. User clicks `Export` in dialog footer
5. Dialog Export button becomes `Generating...` (disabled, Loader2 spin) — dialog stays open
6. Backend generates file, uploads to R2, returns `{ downloadUrl, exportId }`
7. On success:
   - Dialog closes
   - Sonner `toast.success("Export ready. Click to download.")` fires with a Sonner action button (`actionButtonStyle`, label `"Download"`) that opens `downloadUrl` in a new tab
8. On failure:
   - Dialog closes
   - Sonner `toast.error("Export failed. The file could not be generated. Try again.")` fires

### Format Selector Interaction

- Two card-style radio options rendered side by side
- Click either card to select — no separate radio input element (the card IS the radio affordance)
- Selected card: `border-primary bg-primary/5` + `ring-0` (border is sufficient, no additional ring)
- Keyboard: `Tab` moves between cards, `Space`/`Enter` selects the focused card
- Default on dialog open: XLSX

### Re-download Interaction (on `/admin/exports` history table)

- `Download` icon button (`variant="ghost" size="icon"`) wrapped in shadcn `Tooltip` on each completed row
- Tooltip text `"Re-download"` appears on hover (`side="left"`, delay 400ms)
- Click: opens `exportRecord.downloadUrl` in a new tab (`window.open(url, '_blank')`)
- No intermediate step — direct download
- For Generating rows: button rendered at `opacity-40 cursor-not-allowed disabled`
- For Failed rows: button not rendered (replaced by empty cell)

### Loading States

| Context | Behavior |
|---------|---------|
| Exports history page initial load | `ExportHistorySkeleton` — 5 rows, each with column-width-matched `Skeleton` elements at `h-4 rounded`, `animate-pulse`, `space-y-0` (inside `TableBody`) |
| Export dialog — generating | Export button shows `Loader2 animate-spin` + `"Generating..."`, `disabled`. Format selector and date fields remain visible but non-interactive |
| Export button on data page — generating | Button shows `Loader2 animate-spin` + `"Exporting..."`, `disabled` |
| History table — re-download click | No loading state required — direct `window.open` is instant |

### Hover States

| Element | Hover Behavior |
|---------|---------------|
| Export button (data pages) | `hover:bg-accent hover:text-accent-foreground` — shadcn Button `variant="outline"` default |
| Format selector card (unselected) | `border-muted-foreground/40` — subtle visual affordance |
| History table row | `hover:bg-muted/50` — matches `/admin/users` table row hover |
| Re-download icon button | `hover:bg-muted` — shadcn Button `variant="ghost" size="icon"` default; tooltip appears after 400ms |

### Toast Notifications

All toasts use Sonner (`import { toast } from 'sonner'`) consistent with existing admin pages.

| Event | Toast Type | Copy |
|-------|-----------|------|
| Export generated successfully | `toast.success(...)` with action | `"Export ready. Click to download."` + action button `"Download"` |
| Export failed | `toast.error(...)` | `"Export failed. The file could not be generated. Try again."` |
| (Re-download: no toast — direct open) | — | — |

Sonner action button opens `downloadUrl` in a new tab on click.

```
  <TableCell className="w-[80px] text-right">
    {record.status === 'completed' && (
      <TooltipProvider>
        <Tooltip delayDuration={400}>
          <TooltipTrigger asChild>
            <Button
              variant="ghost"
              size="icon"
              onClick={() => window.open(record.downloadUrl, '_blank')}
              aria-label={`Re-download ${record.reportType} export`}
            >
              <Download className="size-4" />
            </Button>
          </TooltipTrigger>
          <TooltipContent side="left">Re-download</TooltipContent>
        </Tooltip>
      </TooltipProvider>
    )}
    {record.status === 'generating' && (
      <Button variant="ghost" size="icon" disabled className="opacity-40 cursor-not-allowed"
        aria-label="Export in progress">
        <Loader2 className="size-4 animate-spin" />
      </Button>
    )}
  </TableCell>
</TableRow>
```
