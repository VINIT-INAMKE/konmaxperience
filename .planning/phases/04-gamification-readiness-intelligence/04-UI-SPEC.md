## Page Layout Contracts

### `/dashboard` — Mission Control Center

Layout: Single column, `space-y-8`. No tabs. Sections in order:

1. **Page header**: "Mission Control" h1 (28px semibold) + AdminUserFilter if FOUNDER_ADMIN
2. **Readiness Strip** (`DashboardReadinessStrip`): Horizontal scroll row of mini rings showing the 4–5 lowest-percentage meters. Mini ring diameter: 64px. Label below ring: meter name 12px. Selection: bottom N meters sorted by `current_value ASC`.
3. **KPI Attention** (`DashboardKpiAlert`): MagicCard grid, 2 columns. Shows top 3–4 at_risk + off_track KPIs. Each card: name, domain, current vs target, status badge. "View All KPIs" link at section footer.
4. **Leaderboard Preview** (`DashboardLeaderboardPreview`): Compact top-5 ranked list. AvatarCircles showing top 3 avatars. NumberTicker for XP values. "View Leaderboard" link. Hidden entirely if kill switch is off.

### `/readiness` — Readiness Intelligence

Layout: Single column page with page header.

1. **Page header**: "Readiness Intelligence" h1 + subtitle "All values derived from validated task completions" (14px muted)
2. **Full ring grid** (`ReadinessGrid`): Responsive CSS grid — 4 columns on xl, 3 columns on lg, 2 columns on md, 1 column on sm. `gap-6`. BlurFade stagger delay 0.05s per ring.
3. **Ring click → MeterDetailPanel**: Slide-down panel beneath the clicked ring row (not modal). Shows: meter name, current %, valid task list (`AnimatedList`), task name + XP + who completed it. Close button top-right.

### `/leaderboard` — Team Leaderboard

Layout: Single column. Hidden if kill switch is off (shows paused state instead).

1. **Kill switch off state**: Card with centered text "Leaderboard is currently paused" (muted), 14px, no further content.
2. **Podium section** (`LeaderboardPodium`): Three columns. Center column (rank 1) elevated by 20px using `translateY(-20px)`. Each column: Avatar (48px), HyperText name, level badge, XP (NumberTicker). ShineBorder wraps current user's column only.
3. **Rankings table** (`LeaderboardTable`): shadcn Table. Columns: Rank, User (avatar + HyperText name), Level badge, XP (NumberTicker), Tasks Validated count. MagicCard wraps each row? No — wraps the table container. Current user row: ShineBorder wrapper + `bg-primary/5` row highlight.
4. **Recent level-ups strip**: AvatarCircles + "{Name} just reached Level {N}!" text. TextAnimate on the level number. Shows last 3 level-up events.

### `/kpis` — KPI Management

Layout: Single column with page header + action button.

1. **Page header**: "KPI Tracker" h1 + ShimmerButton "Create KPI" (admin/BI Lead only, scoped by permission)
2. **Domain filter tabs** (shadcn Tabs): Tab per domain (All, Backend, Frontend, Procurement, etc.). Default: All.
3. **KPI grid**: 3-column grid on xl, 2-column on lg, 1-column on sm. `gap-4`. Each KPI = MagicCard wrapping KPI card content.
4. **KPI Sheet** (shadcn Sheet, side right): Create/edit form. Fields: name, description, domain (select), unit, current_value (number), target_value (number), status (select: on_track/at_risk/off_track), linked_task_ids (combobox multi). Submit: ShimmerButton "Save KPI". Cancel: ghost Button "Cancel".

## Interaction Contracts

### Readiness Meter Ring

- **Idle**: Animated circular progress bar, color-coded stroke, NumberTicker percentage, meter name label below.
- **Hover**: `interactive-hover-button` "View Tasks" appears overlaid on ring center. Ring slight scale-up: `hover:scale-105 transition-transform duration-200`.
- **Click**: MeterDetailPanel expands below the ring row with BlurFade animation. Clicking same ring again collapses it. Only one panel open at a time.
- **Loading**: Ring renders at 0% with shimmer on the label, then animates to actual value on data load.

### XP Sidebar Display

- **Normal state**: "1,250 XP" via NumberTicker (no animation) + LevelBadge pill.
- **Post-validation**: NumberTicker animates from old XP to new XP over 800ms. Sonner toast "Task validated! +{N} XP earned." fires simultaneously.
- **Level-up**: After NumberTicker completes: confetti burst (LevelUpCelebration component), ShineBorder or BorderBeam activates on sidebar XP section for 3s, TextAnimate "Level Up!" overlay toast, Sonner toast "Level up! You're now Level {N}".

### KPI Card

- **on_track**: MagicCard normal state. Standard card with green status badge.
- **at_risk**: MagicCard + PulsatingButton replaces standard edit button. Amber badge. Draws attention without blocking.
- **off_track**: MagicCard with red status badge. PulsatingButton on edit. No additional animation.
- **Edit**: Clicking KPI card opens Sheet from right. Form pre-filled. ShimmerButton submit.

### Leaderboard Kill Switch

- **Toggle location**: Admin Settings page (existing). Switch component labeled "Enable Leaderboard". Off state: leaderboard page shows paused state, sidebar link hidden, dashboard preview section hidden.
- **Toggle confirmation**: Disabling shows Dialog: "Disable leaderboard? Users will no longer see rankings. XP and levels continue to accumulate silently." Confirm button: destructive Button "Disable Leaderboard". Cancel: ghost Button "Cancel".

### Task Card XP Display

- **Any task**: "+{N} XP" Badge (outline variant) displayed in card footer. Value = task XP based on type (Core 100%, Adhoc 70%, Improvement 80%).
- **Validated task**: Green checkmark icon (lucide `CheckCircle2`, `text-green-500`, 16px) + "{N} XP earned" Badge (green outline). CoolMode wraps the checkmark area — particles on hover for validated tasks.

## Accessibility Contract

- All readiness meter rings must have `aria-label="{Meter Name}: {N}% ready"` on the interactive element.
- Leaderboard table must use semantic `<table>` with `<th scope="col">` headers.
- LevelBadge pill must have `aria-label="Level {N}"` for screen readers (badge text alone may be truncated).
- Confetti component must not block keyboard focus — rendered as `aria-hidden="true"`.
- Kill switch Dialog must trap focus and return focus to the toggle on close.
- Color is never the sole indicator — readiness meter rings also show the percentage text (not just color).
- CoolMode particles: `aria-hidden="true"` on particle container.
