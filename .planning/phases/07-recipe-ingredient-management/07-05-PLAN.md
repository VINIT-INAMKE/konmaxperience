**RecipeDependencyTree.tsx** (per D-03, UI-SPEC, Research Pattern 6):
Recursive React component. Props: lines (RecipeLine[]), depth (number, default 0).

Renders a nested indented list. Each level indented by `depth * 16` px (via style paddingLeft).

For each line:
- If input_type === 'ingredient': Show Leaf icon (lucide `Leaf`, size-3.5 text-muted-foreground) + ingredient name (text-sm) + qty + unit (text-xs text-muted-foreground). NOT clickable.
- If input_type === 'recipe': Show ChefHat icon + Link to `/operations/recipes/${source_recipe_id}` (text-sm, underline-offset-2, hover:underline, cursor-pointer) + qty + unit. Then recursively render the source_recipe's RecipeLines at depth+1.

If no lines (empty): show "No sub-recipes" text with "This recipe uses only raw ingredients." (per UI-SPEC empty state).
