  <action>
    1. Install AWS SDK packages: `cd backend && npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner`

    2. Create `backend/src/storage/r2.config.ts`:
       - Export a factory function that creates S3Client configured for R2
       - `region: 'auto'`, `endpoint: process.env.R2_ENDPOINT`
       - Credentials from `R2_ACCESS_KEY_ID` and `R2_SECRET_ACCESS_KEY`
       - Do NOT set forcePathStyle

    3. Create `backend/src/storage/dto/presign.dto.ts`:
       - PresignDto with fields: `filename` (string, not empty), `contentType` (string, not empty), `fileSize` (number), `taskId` (string UUID)
       - class-validator decorators: @IsString, @IsNotEmpty, @IsNumber, @IsUUID

    4. Create `backend/src/storage/storage.service.ts`:
       - Injectable service, constructor receives PrismaService (for task ownership check)
       - `ALLOWED_MIME_TYPES` Set: 'image/jpeg', 'image/png', 'image/webp', 'application/pdf', 'application/vnd.openxmlformats-officedocument.wordprocessingml.document', 'video/mp4', 'video/webm'
       - `MAX_FILE_SIZE = 10 * 1024 * 1024` (10 MB)
       - `generatePresignedPutUrl(key: string, contentType: string): Promise<string>` — uses PutObjectCommand + getSignedUrl with expiresIn: 900 (15 min)
       - `validatePresignRequest(contentType: string, fileSize: number)` — throws BadRequestException for invalid MIME or size > 10 MB
       - `buildStorageKey(taskId: string, filename: string): string` — returns `evidence/{taskId}/{timestamp}-{sanitized-filename}` where sanitized removes special chars
       - `getPublicUrl(key: string): string` — returns `${process.env.R2_PUBLIC_URL}/${key}`

    5. Create `backend/src/storage/storage.controller.ts`:
       - `POST /storage/presign` protected by @RequiresPermission(Permission.UPLOAD_EVIDENCE)
       - Validates content type and file size via service.validatePresignRequest
       - Verifies the requesting user is the task owner OR has UPDATE_ANY_TASK permission (admin) — fetch task by taskId and compare owner_user_id
       - Builds storage key, generates presigned URL
       - Returns `{ presignedUrl, key, publicUrl }` — publicUrl is the permanent URL for later retrieval

    6. Create `backend/src/storage/storage.module.ts`:
       - Imports PrismaModule
       - Provides StorageService
       - Exports StorageService (used by EvidenceModule)
       - Controllers: StorageController

    7. Add to `backend/.env.example`:
       ```
       # Cloudflare R2 (Evidence Storage)
       R2_ENDPOINT=https://YOUR_ACCOUNT_ID.r2.cloudflarestorage.com
       R2_ACCESS_KEY_ID=your-r2-access-key
       R2_SECRET_ACCESS_KEY=your-r2-secret-key
       R2_BUCKET_NAME=konma-evidence
       R2_PUBLIC_URL=https://your-bucket-public-url.r2.dev
       ```
  </action>
