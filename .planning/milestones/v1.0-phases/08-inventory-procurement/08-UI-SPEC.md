## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, table cell icon-button spacing |
| sm | 8px | Compact table cell padding, form field gap, badge gap |
| md | 16px | Default card padding, section header gap, form group spacing |
| lg | 24px | Section padding, page header bottom margin |
| xl | 32px | Between page sections, PO form group separation |
| 2xl | 48px | Major section breaks on full-page PO form |
| 3xl | 64px | Page-level top padding |

Exceptions:
- Table row cells use `px-4 py-2` (16px horizontal, 8px vertical) — standard set values
- Icon action buttons use `p-2` (8px) — standard set value, compact icon button padding
- Touch targets for primary actions: minimum 44px height

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Table cell content, form labels, description text |
| Label | 12px (text-xs) | 400 (regular) | 1.4 | Badge text, secondary metadata, unit display, muted hints |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Page titles, section headings |
| Display | 28px (text-2xl) | 600 (semibold) | 1.2 | Procurement dashboard summary numbers (via NumberTicker) |

Notes:
- Numeric quantities (stock levels, amounts, received_qty) rendered in `font-mono text-xs text-muted-foreground` — matches Phase 7 IngredientRow base_unit pattern
- Font: `var(--font-geist-sans)` globally, `var(--font-geist-mono)` for stock quantities and INR amounts
- Only 2 weights used: 400 (regular) and 600 (semibold)

**Layout:** Full-width table with page header + filter bar + alert strip

**Sections:**
- Page header: "Inventory" h1 + "Adjust Stock" secondary button (Sheet trigger)
- Low-stock alert strip: amber Alert component showing count of ingredients below minimum — "N ingredients below minimum stock level. Review and reorder."
- Filter bar: category filter Select + zone filter Select + search Input
- Stock table: all ingredients with columns: Name | Category | Zone | Current Stock | Min Level | Status | Actions

**Table row columns:**
- Name: `text-sm font-medium`
- Category: colored Badge (existing CATEGORY_COLORS from IngredientRow)
- Zone: `text-sm text-muted-foreground`
- Current Stock: `font-mono text-sm` — red/amber text when below minimum, green when healthy
- Min Level: `font-mono text-xs text-muted-foreground`
- Status: Badge — "Low Stock" (amber) or "OK" (muted)
- Actions: Tooltip-wrapped "View Movements" icon button (History icon, 14px)

**Empty state:** "No ingredients found. Add ingredients first in the Ingredients section."

## Interaction Contracts

### PO Line Item Table
- "Add Item" button appends an empty row immediately — no modal
- Deleting a row: icon button with `hover:text-destructive` — no confirmation needed (draft action)
- Line total auto-calculates on any qty/cost change (client-side, no API call)
- Grand total at bottom updates in real-time via NumberTicker animation on value change
- At least one line item required before "Save" is enabled

### PO Status Transitions
- Draft → Ordered: "Save and Mark as Ordered" button (PO creation form)
- Ordered → Received: "Mark as Received" button on detail page (requires Dialog confirmation)
- Any → Cancelled: X icon or "Cancel PO" button → Dialog confirmation
- No other manual transitions (received is terminal, cancelled is terminal)

### Receiving Flow
- received_qty fields default to ordered_qty value on load
- Partial receiving: received_qty can be less than ordered_qty (no validation block)
- Zero received_qty rows: allowed (ingredient simply not received, no StockMovement created)
- "Mark as Received" disabled until at least one received_qty > 0
- After confirmation: Sonner toast "Receiving recorded. Stock levels updated." (success)

### Manual Stock Adjustment (Sheet)
- Trigger: "Adjust Stock" button on Inventory page header
- Fields: Ingredient (Select), Zone (Select), Quantity (signed number — negative for deduction), Reason (text), Movement Type (adjustment pre-selected)
- Submit: "Save Adjustment" button
- After submit: sheet closes, inventory table row updates, Sonner toast "Stock adjusted."

### Low-Stock Badge on IngredientRow
- Condition: `current_quantity < min_stock_level` (fetched via IngredientStock)
- Visual: amber Badge "Low Stock" — no animation, no pulse (urgency communicated by color)
- Tooltip on quantity cell: "Below minimum of {min_stock_level} {base_unit}"
