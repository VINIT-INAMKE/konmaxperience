**InventoryModule — 3 endpoints:**

`GET /inventory` — returns all IngredientStock records with ingredient (name, category, base_unit, min_stock_level) and zone (name) included. No permission guard — all authenticated users can view (consistent with Phase 6 Operations visibility). Also add a `low_stock` boolean computed field: `Number(current_quantity) < Number(ingredient.min_stock_level)`.

`GET /inventory/:ingredientId/movements` — returns all StockMovement records for an ingredient, ordered by created_at DESC, with creator (name) included. No permission guard.

`POST /inventory/adjust` — requires `MANAGE_INVENTORY` permission. DTO fields: ingredient_id (UUID, required), zone_id (UUID, required), quantity (number, required — signed, negative for deduction), unit (string, required), reason (string, required). Service method uses `prisma.$transaction` to atomically:
1. Upsert IngredientStock (increment current_quantity by the quantity value after unit conversion to base_unit)
2. Create StockMovement with movement_type='adjustment', original_quantity=Math.abs(dto.quantity), unit=dto.unit, quantity=converted value in base_unit
CRITICAL per Research Pitfall 2: pass `tx` (not `this.prisma`) to `convertUnit()` inside the transaction.
CRITICAL per Research Pitfall 4: use `Number()` for Decimal comparisons.

`GET /inventory/low-stock` — returns IngredientStock records where current_quantity < ingredient.min_stock_level. Application-level filter (post-fetch), not raw query. Returns array of IngredientStock with ingredient info. Used by dashboard widget.

**PurchaseOrdersModule — 6 endpoints:**

`GET /purchase-orders` — list all POs with vendor (name), zone (name), lines count. Optional query param `status` to filter. No permission guard (viewable by all authenticated). Order by created_at DESC.

`POST /purchase-orders` — requires `MANAGE_PROCUREMENT` permission. DTO: vendor_id (UUID), zone_id (UUID), notes (string, optional), status (enum draft|ordered, default 'draft'), lines array of { ingredient_id (UUID), quantity (number, positive), unit (string), unit_cost (number, positive) }. Calculate total_amount as sum of (quantity * unit_cost) per line. If status is 'ordered', set ordered_at to new Date(). Use `prisma.$transaction` to create PO + all lines atomically.

`GET /purchase-orders/:id` — returns single PO with vendor, zone, ordered_by_user (name), and lines (with ingredient name, base_unit). No permission guard.

`PATCH /purchase-orders/:id` — requires `MANAGE_PROCUREMENT`. Allow updating notes and transitioning status from draft to ordered (set ordered_at). Do NOT allow any other status transitions via PATCH.

`POST /purchase-orders/:id/receive` — requires `MANAGE_PROCUREMENT`. This is the critical receiving transaction per pipeline spec section 4.5:
DTO: lines array of { id (string — PurchaseOrderLine id), received_quantity (number) }.

```typescript
async receivePurchaseOrder(poId: string, dto: ReceivePurchaseOrderDto, userId: string) {
  return this.prisma.$transaction(async (tx) => {
    const po = await tx.purchaseOrder.findUniqueOrThrow({
      where: { id: poId },
      include: { lines: true },
    });
    if (po.status !== 'ordered') throw new BadRequestException('PO must be in ordered status');

    let totalReceived = new Decimal(0);

    for (const lineReceived of dto.lines) {
      if (!lineReceived.received_quantity || lineReceived.received_quantity <= 0) continue;

      const poLine = po.lines.find((l) => l.id === lineReceived.id);
      if (!poLine) continue;

      const ingredient = await tx.ingredient.findUniqueOrThrow({
        where: { id: poLine.ingredient_id },
      });

      // Convert procurement unit to base_unit — pass tx, not this.prisma (Pitfall 2)
      const qtyBase = await convertUnit(
        lineReceived.received_quantity,
        poLine.unit,
        ingredient.base_unit,
        tx,
      );
      if (qtyBase === null) throw new BadRequestException(
        `No unit conversion from ${poLine.unit} to ${ingredient.base_unit}`
      );

      // Upsert IngredientStock (getOrCreate pattern)
      await tx.ingredientStock.upsert({
        where: {
          ingredient_id_zone_id: {
            ingredient_id: poLine.ingredient_id,
            zone_id: po.zone_id,
          },
        },
        create: {
          ingredient_id: poLine.ingredient_id,
          zone_id: po.zone_id,
          current_quantity: qtyBase,
        },
        update: { current_quantity: { increment: qtyBase } },
      });

      // Create StockMovement
      await tx.stockMovement.create({
        data: {
          ingredient_id: poLine.ingredient_id,
          zone_id: po.zone_id,
          movement_type: 'received',
          quantity: qtyBase,
          original_quantity: lineReceived.received_quantity,
          unit: poLine.unit,
          reference_type: 'purchase_order',
          reference_id: poId,
          created_by: userId,
        },
      });

      // Update line received_quantity
      await tx.purchaseOrderLine.update({
        where: { id: poLine.id },
        data: { received_quantity: lineReceived.received_quantity },
      });

      totalReceived = totalReceived.add(
        new Decimal(lineReceived.received_quantity).mul(new Decimal(Number(poLine.unit_cost)))
      );
    }

    return tx.purchaseOrder.update({
      where: { id: poId },
      data: { status: 'received', received_at: new Date(), total_amount: totalReceived },
      include: { lines: { include: { ingredient: true } }, vendor: true, zone: true },
    });
  });
}
```

Import `Decimal` from `@prisma/client/runtime/library` (Prisma v6 pattern) or `decimal.js`.

4. **total_inventory_value:** For each unique ingredient_id in IngredientStock, get latest VendorPrice. Sum `current_quantity_in_base_unit * (price / conversion_factor_to_base_unit)`. If no vendor price exists for an ingredient, value is 0.
```typescript
const stocks = await this.prisma.ingredientStock.findMany({
  include: { ingredient: true },
});
const ingredientIds = [...new Set(stocks.map((s) => s.ingredient_id))];
let totalValue = 0;
for (const ingId of ingredientIds) {
  const latestPrice = await this.prisma.vendorPrice.findFirst({
    where: { ingredient_id: ingId },
    orderBy: { effective_date: 'desc' },
  });
  if (!latestPrice) continue;
  const stocksForIng = stocks.filter((s) => s.ingredient_id === ingId);
  const totalQty = stocksForIng.reduce((sum, s) => sum + Number(s.current_quantity), 0);
  // current_quantity is in base_unit, price is per price.unit — need conversion
  const factor = await convertUnit(1, latestPrice.unit, stocks.find(s => s.ingredient_id === ingId)!.ingredient.base_unit, this.prisma);
  const pricePerBaseUnit = factor ? Number(latestPrice.price) / factor : Number(latestPrice.price);
  totalValue += totalQty * pricePerBaseUnit;
}
```
