    **2. Create `backend/src/analytics/analytics.service.ts`:**
    - Inject `PrismaService`
    - Helper: `private parseDateRange(from: string, to: string): { start: Date, end: Date }` using IST pattern: `new Date(\`${from}T00:00:00+05:30\`)` and `new Date(\`${to}T23:59:59+05:30\`)`

    Methods:

    a) `async getSummary(from: string, to: string)` — returns `{ total_revenue: number, avg_food_cost_pct: number, total_orders: number, avg_order_value: number }`
       - Query orders where `created_at: { gte: start, lte: end }` and `status: { not: 'cancelled' }`
       - Include `payment` and `items: { include: { menu_item: { select: { food_cost_percent: true } } } }`
       - total_revenue = sum of `Number(order.total)` where `order.payment?.status === 'paid'`
       - total_orders = orders.length
       - avg_order_value = total_revenue / total_orders (or 0)
       - avg_food_cost_pct = weighted average: sum(MenuItem.food_cost_percent * OrderItem.quantity) / sum(OrderItem.quantity) across all order items. Use `Number()` for Decimal fields.

    b) `async getRevenueSeries(from: string, to: string)` — returns `Array<{ date: string, revenue: number }>`
       - Query orders with payment included, filter `payment.status === 'paid'`, status not cancelled
       - Group by IST date using `order.created_at.toLocaleDateString('en-CA', { timeZone: 'Asia/Kolkata' })`
       - Return array sorted by date ascending

    c) `async getTopItems(from: string, to: string)` — returns `Array<{ menu_item_id: string, name: string, quantity_sold: number, revenue: number }>` (top 10)
       - Use `prisma.orderItem.groupBy({ by: ['menu_item_id'], where: { order: { created_at: { gte, lte }, status: { not: 'cancelled' } } }, _sum: { quantity: true }, orderBy: { _sum: { quantity: 'desc' } }, take: 10 })`
       - Enrich with MenuItem names via separate `prisma.menuItem.findMany({ where: { id: { in: menuItemIds } }, select: { id, name, base_price } })`
       - Revenue = quantity_sold * Number(base_price)

    d) `async getChannelBreakdown(from: string, to: string)` — returns `Array<{ channel: string, revenue: number, order_count: number }>`
       - Query orders (not cancelled, paid payment, in date range)
       - Group by `channel` field using a Map, accumulate revenue and count

    e) `async getRecipeCosts(from: string, to: string)` — returns `Array<{ recipe_id: string, recipe_name: string, computed_cost: number, selling_price: number, food_cost_pct: number, units_sold: number }>`
       - Query order items in date range grouped by menu_item_id with _sum quantity
       - Load MenuItems with `recipe: { select: { id, name, computed_cost } }` and `base_price, food_cost_percent`
       - Map to result, sort by food_cost_pct descending

    f) `async getWins(limit: number, cursor?: string)` — returns `Array<{ id: string, type: 'quest_completed' | 'task_validated', title: string, actor_name: string, actor_role: string, timestamp: string }>`
       - Query completed quests: `prisma.quest.findMany({ where: { status: 'completed' }, include: { owner: { select: { name, roleName } } }, orderBy: { updated_at: 'desc' }, take: limit })`
       - Query validated tasks: `prisma.task.findMany({ where: { valid: true, completed_at: { not: null } }, include: { assigned_user: { select: { name, roleName } } }, orderBy: { completed_at: 'desc' }, take: limit })`
       - If cursor provided, add `updated_at: { lt: new Date(cursor) }` / `completed_at: { lt: new Date(cursor) }` respectively
       - Merge both arrays, sort by timestamp desc, take first `limit` entries
       - Return with `type` discriminator and ISO timestamp string
