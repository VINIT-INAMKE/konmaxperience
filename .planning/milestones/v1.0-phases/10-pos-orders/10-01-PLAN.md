    3. **OrdersService** — `backend/src/orders/orders.service.ts` with PrismaService injection:

    `createOrder(dto, userId)` — Use `prisma.$transaction`:
      a. Compute subtotal from dto.items: `sum(item.unit_price * item.quantity)`
      b. Look up ChannelModifier via `tx.channelModifier.findFirst({ where: { channel_type: dto.channel, status: 'active' } })` (use findFirst not findUnique per Pitfall 5 — null-check gracefully)
      c. Compute modifierAmount: if modifier exists, fixed = Number(modifier.modifier_value), percentage = subtotal * Number(modifier.modifier_value) / 100; else 0
      d. Create Order with `tx.order.create({ data: { channel, status: 'placed', subtotal, channel_modifier_amount: modifierAmount, total: subtotal + modifierAmount, zone_id: dto.zone_id, created_by: userId, table_number, customer_name, customer_phone, delivery_address, delivery_assigned_to, notes, items: { create: dto.items.map(i => ({ menu_item_id: i.menu_item_id, quantity: i.quantity, unit_price: i.unit_price, item_notes: i.item_notes, status: 'pending' })) } }, include: { items: true, payment: true } })`
      e. Return the order

    `getOrders(filters: OrderFiltersDto)` — Build Prisma WHERE clause per Research Pattern 3:
      - channel, status filters as exact match
      - date_from/date_to on created_at as gte/lte
      - payment_method as `where.payment = { method: filters.payment_method }`
      - search: if present, OR condition on `id CONTAINS search` (for order ID fragment match)
      - Include `items: { select: { id: true } }` and `payment: true`
      - orderBy created_at desc

    `updateOrderStatus(orderId, newStatus)`:
      - Valid progressions: placed->preparing, preparing->ready (manual override), ready->served, ready->dispatched. Cancelled from any non-terminal (not served, not dispatched, not cancelled).
      - Throw BadRequestException for invalid transition.
      - Return updated order.

    `recordPayment(orderId, dto: RecordPaymentDto)`:
      - Check if Payment already exists for this order. If so, throw ConflictException (409) with message "Payment already recorded for this order" per Research Pitfall 7.
      - Create Payment with `prisma.payment.create({ data: { order_id: orderId, method: dto.method, amount: dto.amount, status: 'paid', notes: dto.notes } })`.
      - Return the payment.

    `updateDelivery(orderId, dto: UpdateDeliveryDto)`:
      - Validate delivery_status progression: null/undefined->picked_up->in_transit->delivered. Throw BadRequestException for invalid transition.
      - Update Order with delivery_assigned_to and/or delivery_status.
      - Return updated order.

    `getDailySummary(date: string)`:
      - Parse date as YYYY-MM-DD. Compute start = date + T00:00:00+05:30 (IST), end = start + 1 day per Research Pitfall 6.
      - Query: `prisma.order.findMany({ where: { created_at: { gte: start, lt: end }, status: { not: 'cancelled' } }, include: { payment: true } })`
      - Aggregate: totalOrders = count, totalRevenue = sum of order.total where payment.status === 'paid', averageOrderValue = totalRevenue / totalOrders (or 0).
      - Return `{ total_orders, total_revenue, average_order_value }`.
