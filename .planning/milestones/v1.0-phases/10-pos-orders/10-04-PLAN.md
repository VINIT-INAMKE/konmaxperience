Backend endpoints (Plan 01):
```
GET /orders?channel=&status=&date_from=&date_to=&payment_method=&search= → Order[]
GET /orders/:id → Order (with items + payment)
GET /orders/daily-summary?date=YYYY-MM-DD → DailySummary
PATCH /orders/:id/status → { status: string }
POST /orders/:id/payment → Payment
```
