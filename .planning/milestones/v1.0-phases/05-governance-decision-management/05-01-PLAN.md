`decisions.service.ts` — Injectable class with PrismaService injection:
- `findAll(status?: string)`: Query decisions with optional status filter. Include proposer (id, name), linked_mission (id, title), linked_task (id, title). Order by created_at desc.
- `findOne(id: string)`: Find by id with same includes. Throw NotFoundException if not found.
- `create(dto: CreateDecisionDto, proposerId: string)`: Create with `impact_scope: 'ops'` default (impact_scope is required in schema but not in form per research open question 3), `status: 'proposed'`, `proposed_by: proposerId`.
- `update(id: string, dto: UpdateDecisionDto, userId: string, isAdmin: boolean)`: Find decision first. Per D-04: if current status is 'approved' and caller is NOT admin, throw ForbiddenException('Approved decisions are locked. Only admin can reopen.'). If dto.status is 'proposed' (reopen) and caller is NOT admin, throw ForbiddenException. Apply update. Return with includes.
- `remove(id: string, isAdmin: boolean)`: Find decision. Per D-04: if status is 'approved', throw ForbiddenException('Cannot delete an approved decision'). If not admin and status is not 'proposed', throw ForbiddenException. Delete and return.

`decisions.controller.ts`:
- `@Controller('decisions')` class
- `@Get()` — no permission guard (all authenticated users can view per D-17). Accepts optional `@Query('status')` filter. Calls `service.findAll(status)`.
- `@Get(':id')` — no permission guard. Calls `service.findOne(id)`.
- `@Post()` with `@RequiresPermission(Permission.CREATE_DECISION)` per D-01. Extract `user.id` from request. Calls `service.create(dto, user.id)`.
- `@Patch(':id')` with `@RequiresPermission(Permission.APPROVE_DECISION)` for status changes. Extract user.id and check `user.roleCode === 'FOUNDER_ADMIN'` for isAdmin. Calls `service.update(id, dto, user.id, isAdmin)`.
- `@Delete(':id')` with `@RequiresPermission(Permission.APPROVE_DECISION)`. Calls `service.remove(id, isAdmin)`.

`decisions.module.ts`: Standard module importing nothing extra, registering controller and service.

- `approveWithDelegation(approvalId: string, actingUserId: string, actingRoleCode: string)` per D-13, D-14:
  This method handles the case where a delegate approves on behalf of an absent user. The logic:
  1. Check if the acting user has APPROVE_EVIDENCE permission from their own role (via getPermissionsForRole). If yes, proceed normally -- no delegation needed.
  2. If NOT, check for active delegation via `this.delegationsService.getActiveDelegationForUser(actingUserId)`.
  3. If active delegation found, set `delegated_from_user_id` on the Approval record to `delegation.from_user_id`.
  4. If no delegation and no own permission, throw ForbiddenException.

  ```typescript
  async approveWithDelegation(approvalId: string, actingUserId: string, actingRoleCode: string) {
    const ownPerms = await getPermissionsForRole(actingRoleCode, this.prisma);
    let delegatedFromUserId: string | null = null;

    if (!ownPerms.includes(Permission.APPROVE_EVIDENCE)) {
      const delegation = await this.delegationsService.getActiveDelegationForUser(actingUserId);
      if (!delegation) {
        throw new ForbiddenException('No permission to approve and no active delegation');
      }
      delegatedFromUserId = delegation.from_user_id;
    }

    return this.prisma.$transaction(async (tx: any) => {
      const approval = await tx.approval.findUnique({ where: { id: approvalId } });
      if (!approval) throw new NotFoundException(`Approval ${approvalId} not found`);

      await tx.approval.update({
        where: { id: approvalId },
        data: {
          status: 'approved',
          approved_by: actingUserId,
          delegated_from_user_id: delegatedFromUserId,
        },
      });

      if (approval.entity_type === 'evidence') {
        await tx.evidence.update({
          where: { id: approval.entity_id },
          data: { approval_status: 'approved', reviewed_by: actingUserId, reviewed_at: new Date() },
        });
        const evidence = await tx.evidence.findUnique({ where: { id: approval.entity_id } });
        if (evidence) {
          return this.evidenceService.validateTask(evidence.task_id, tx);
        }
      }

      return { approved: true, delegated_from: delegatedFromUserId };
    });
  }
  ```

  Import `getPermissionsForRole` from `../permissions/permissions.cache` and `Permission` from `../types/permissions`.
